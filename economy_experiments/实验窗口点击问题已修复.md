# ✅ 实验窗口无法点击问题 - 已修复

## 🔧 已修复的问题

实验窗口无法点击是因为UI层级设置不正确，导致面板被其他UI元素遮挡。

### 修复内容

1. ✅ **使用 CanvasLayer** - 确保实验面板在独立的UI层
2. ✅ **设置高层级** - layer = 100，保证在最上层
3. ✅ **启用鼠标事件** - mouse_filter = MOUSE_FILTER_STOP
4. ✅ **添加关闭按钮** - 在面板右上角添加 ✖ 按钮

var dragging = false
var drag_offset = Vector2.ZERO

func _input(event):
	if event is InputEventMouseButton:
		if event.button_index == MOUSE_BUTTON_LEFT:
			if event.pressed:
				# 检查是否点击在面板标题区域

				if Rect2(Vector2.ZERO, Vector2(size.x, 40)).has_point(local_pos):

## 📊 技术细节

### CanvasLayer 层级说明

Godot 的 CanvasLayer 系统：

- **layer 0-99**: 游戏世界和普通UI
- **layer 100+**: 始终在最上层
- **layer 值越大越在上面**

我们使用 layer 100 确保实验面板：
- 在所有游戏内容之上
- 在普通UI之上
- 不会被其他元素遮挡

### mouse_filter 选项

```gdscript
MOUSE_FILTER_STOP    # 0 - 接收事件，阻止传递（我们使用的）
MOUSE_FILTER_PASS    # 1 - 接收事件，继续传递
MOUSE_FILTER_IGNORE  # 2 - 忽略事件，继续传递
```

我们使用 `MOUSE_FILTER_STOP` 确保：
- 面板接收所有鼠标事件
- 点击不会穿透到下层
