# 🔧 实验日志问题修复说明

## 问题原因

之前日志不显示的原因是：**游戏信号连接得太晚了**

### 原来的流程（错误）
```
1. 调用 experiment_manager.run_game()
2. 游戏在内部启动并立即执行
3. 游戏返回后才连接信号
4. ❌ 所有事件已经发生，信号连接太晚
```

### 现在的流程（正确）
```
1. 手动创建游戏实例（不启动）
2. ✅ 先连接所有信号
3. 添加参与者
4. 启动游戏
5. ✅ 所有事件都能被捕获
```

## 🔧 修复内容

### 1. 直接创建游戏实例
```gdscript
# 不再使用
var game = experiment_manager.run_game(...)

# 改为直接创建
var game = TrustGame.new(game_config)
```

### 2. 信号优先连接
```gdscript
# 创建游戏
var game = TrustGame.new(game_config)

# 立即连接信号（在启动之前！）
_connect_game_signals(game)

# 添加参与者
game.add_player(agent)

# 最后启动
game.start_game()
```

### 3. 添加调试日志
在Console中可以看到：
```
GameExperimentPanel: 游戏信号已连接 - trust
GameExperimentPanel: 游戏开始事件触发 - trust
GameExperimentPanel: 回合开始 - 1
GameExperimentPanel: 决策 - send by Alice
GameExperimentPanel: 决策 - return by Jack
```

### 4. 导入必要的类
```gdscript
const TrustGame = preload("res://economy_experiments/scripts/behavioral_games/TrustGame.gd")
const UltimatumGame = preload("res://economy_experiments/scripts/behavioral_games/UltimatumGame.gd")
const PublicGoodsGame = preload("res://economy_experiments/scripts/behavioral_games/PublicGoodsGame.gd")

```

## 🐛 调试方法

### 1. 检查Console输出
按F12或打开Godot的Output窗口，查看：
```
GameExperimentPanel: 游戏信号已连接 - trust
GameExperimentPanel: 游戏开始事件触发 - trust
GameExperimentPanel: 回合开始 - 1
GameExperimentPanel: 决策 - send by Alice
```

如果看到这些，说明信号正常工作。

### 2. 检查日志面板
- 左侧应该有实时更新的彩色日志
- 日志应该自动滚动到底部
- 时间戳应该是当前时间

### 3. 检查参与者数量
如果看到：
```
❌ 游戏启动失败 - 检查参与者数量是否足够
```

说明选择的参与者不够，比如：
- 信任游戏需要2人
- 公共物品游戏需要4人

### 4. 确认选择了参与者
在参与者列表中：
- 使用Ctrl/Cmd+点击多选
- 选中的会高亮显示
- 至少选择游戏要求的最少人数
