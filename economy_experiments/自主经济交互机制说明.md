# 🤖 自主经济交互机制说明

## 📋 概述

除了由研究员手动触发的“标准实验”（如信任游戏、最后通牒博弈）外，Microverse 中的 AI Agent 还具备**自主经济决策能力**。

这一机制由 `EconomicDecisionMaker` 模块驱动，允许 Agent 在场景中自由活动时，根据自身的性格、财富状态和心理状况，主动向其他 Agent 发起经济交互。

---

## 🔄 决策周期

- **触发频率**：每个 Agent 约每 15 秒进行一次决策判定。
- **冷却时间**：每次行动后有 15 秒的冷却期。
- **感知范围**：Agent 只能与距离自己 300 像素范围内的其他 Agent 交互。

---

## 💡 决策类型与触发条件

Agent 会根据当前状态评估采取哪种行动：

### 1. 💰 投资 (INVEST)
*   **行为**：向另一个 Agent 转移资金，期望获得回报。
*   **触发条件**：
    *   财富等级较高 (Lv.3+)
    *   风险厌恶低 (Risk Aversion < 0.4)
    *   自信心高 (Confidence > 0.6)
*   **目的**：利用现有资金赚取更多收益，建立合作关系。

### 2. 🤝 交易 (TRADE)
*   **行为**：与另一个 Agent 进行资金交换。
*   **触发条件**：
    *   信任度高 (Trust > 0.6)
    *   满意度高 (Satisfaction > 0.5)
*   **目的**：互惠互利，维持经济流动。

### 3. 🎁 提供帮助 (OFFER_HELP)
*   **行为**：无偿赠予资金给较贫穷的 Agent。
*   **触发条件**：
    *   财富等级较高 (Lv.3+)
    *   利他主义高 (Altruism > 0.6)
*   **目的**：帮助他人，提升社会福利（符合利他性格）。

### 4. 🆘 请求帮助 (REQUEST_HELP)
*   **行为**：向较富有的 Agent 索取资金。
*   **触发条件**：
    *   压力大 (Stress > 0.7)
    *   利他主义高 (相信他人会帮忙)
*   **目的**：度过经济难关。

### 5. 🏗️ 合作 (COOPERATE)
*   **行为**：双方共同出资，平分收益。
*   **触发条件**：
    *   信任度极高
    *   满意度良好
*   **机制**：双方各出一笔钱，总资金乘以 1.1~1.5 倍后平分。这是**唯一能直接创造新财富**的自主行为（其他行为主要是资金转移）。

---

## 🔄 互惠与回报机制 (The Reciprocity Loop)

当 Agent A 向 Agent B 发起 **投资** 或 **交易** 时，会触发内置的互惠逻辑：

1.  **A 发起转账**：A 转账 `amount` 给 B。
2.  **B 决定回报**：B 根据自身的 `reciprocity` (互惠倾向) 参数决定是否回报。
3.  **计算回报额**：
    *   如果 B 决定回报，金额通常在 `amount * 0.5` 到 `amount * 1.2` 之间波动。
    *   这意味着 A 可能会**盈利**（回报 > 100%），也可能会**亏损**（回报 < 100%）。
4.  **资金结算**：B 将计算出的金额转回给 A。

> **注意**：自主交易主要是“零和博弈”或“负和博弈”（考虑到转账本身不产生新钱，除非触发了特定的增益事件），主要用于模拟市场中的资金流动和信任建立过程。只有“合作”行为能从系统中“印钱”。

## 📝 日志解读示例

以下是一次典型的**投资与回报**交互日志分析：

```text
💰 [EconomicAI] Grace 做出经济决策：{ "type": 5, "target": "Monica", "amount": 850.0, "reason": "投资合作" }
```
*   **解读**：Grace 决定向 Monica 发起投资（Type 5 = INVEST），金额 ¥850。

```text
📝 SceneExperimentTracker: Grace 进行了交易: withdraw
💰 SceneExperimentTracker: Grace 的财富变为 ¥9150.00
📝 SceneExperimentTracker: Monica 进行了交易: deposit
💰 SceneExperimentTracker: Monica 的财富变为 ¥10850.00
```
*   **解读**：转账执行。Grace: -850, Monica: +850。此时 Monica 持有资金。

```text
💱 Grace 向 Monica 交易了 ¥850.00 (投资合作)
```
*   **解读**：系统确认交易发生。

```text
📝 SceneExperimentTracker: Monica 进行了交易: withdraw
💰 SceneExperimentTracker: Monica 的财富变为 ¥10394.59
📝 SceneExperimentTracker: Grace 进行了交易: deposit
💰 SceneExperimentTracker: Grace 的财富变为 ¥9605.41
```
*   **解读**：**互惠触发**。Monica 立即向 Grace 回款。
*   **计算**：Monica 转回了 `10850 - 10394.59 = 455.41` 元。
*   **结果分析**：
    *   Grace 投资 850，收回 455.41，净亏损 394.59。
    *   这表明 Monica 在这次交互中选择了较低的回报率（约 53%）。这可能受 Monica 的性格（如自私程度）或随机浮动影响。

```text
🤝 SceneExperimentTracker: 记录交互 - trade (Grace, Monica)
```
*   **解读**：交互结束，系统记录下这次互动，这将作为未来数据分析的样本。
