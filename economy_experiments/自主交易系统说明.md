# 🤖 Agent自主交易系统

## 📋 概述

现在agent可以**自主决定**是否发起交易了！每个agent会根据自己的：
- 💰 财富状况
- 😊 心理状态（心情、压力、满意度）
- 🎭 个性特征（利他性、信任度、风险厌恶）
- 👥 周围的其他agent

来做出独立的经济决策。

---

## ✨ 新增功能

### 1. 经济决策模块 (`EconomicDecisionMaker`)

每个AI agent现在拥有一个经济决策大脑，能够：

- **评估自身状态** - 分析财富、心情、压力、信心
- **感知周围agent** - 发现300像素范围内的其他角色
- **智能决策** - 基于个性和状态选择行动

### 2. 五种决策类型

| 类型 | 图标 | 触发条件 | 效果 |
|------|------|----------|------|
| **交易** | 💱 | 信任度高、满意度高 | 与伙伴互惠交易 |
| **请求帮助** | 🙏 | 压力大、利他性中等 | 向富人请求援助 |
| **提供帮助** | 🎁 | 富裕且利他 | 帮助贫困者 |
| **合作投资** | 🤝 | 信任度高 | 双方投资获利 |
| **投资** | 📈 | 风险厌恶低、有钱 | 投机性交易 |

### 3. 决策逻辑示例

```gdscript
# 如果压力大且需要帮助
if stress > 0.7 and altruism > 0.4:
    → 向最富有的agent请求帮助

# 如果富裕且乐于助人
if wealth_level >= 3 and altruism > 0.6:
    → 帮助最贫困的agent

# 如果信任他人且满意
if trust_level > 0.6 and satisfaction > 0.5:
    → 发起互惠交易

# 如果冒险且自信
if risk_aversion < 0.4 and confidence > 0.6:
    → 进行投资交易
```

运行游戏后，左上角会出现 **💰 经济系统控制** 面板：

```

━━━━━━━━━━━━━━━━━━
☑ 启用自动交易

交易频率（秒）:
[滑块] ────●──── 20s

━━━━━━━━━━━━━━━━━━
📊 交易统计:
💳 交易次数: 15
🤝 交互次数: 8
💰 总财富: ¥80,000
📈 平均财富: ¥10,000
```

**控制选项**:
- ☑️ **启用自动交易** - 开关所有agent的自动交易
- ⏱️ **交易频率** - 调整决策间隔（10-60秒）

### 命令行控制

如果需要手动控制，可以通过代码：

```gdscript
# 获取经济面板

# 切换面板可见性
econ_panel.toggle_panel()

# 手动触发某个agent的交易决策
var ai_agent = $Alice/AIAgent
ai_agent._make_economic_decision()
```

## 🎯 决策参数说明

### 个性参数 (0.0-1.0)

- **altruism** (利他性): 越高越愿意帮助他人
- **trust_level** (信任度): 越高越愿意合作
- **risk_aversion** (风险厌恶): 越低越敢投资
- **reciprocity** (互惠性): 回报他人的倾向

### 心理状态 (0.0-1.0)

- **mood** (心情): 影响决策积极性
- **stress** (压力): 高压力会寻求帮助
- **satisfaction** (满意度): 影响交易意愿
- **confidence** (信心): 影响投资决策

### 财富等级 (1-5)

- **Level 1**: < ¥5,000 (贫困)
- **Level 2**: ¥5,000 - ¥10,000 (普通)
- **Level 3**: ¥10,000 - ¥15,000 (富裕)
- **Level 4**: ¥15,000 - ¥25,000 (很富)
- **Level 5**: > ¥25,000 (极富)
