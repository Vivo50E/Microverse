# 实验报告生成功能已完成 ✅

## 🎉 功能上线

游戏内实验系统现已支持**自动生成本地报告**！

---

## ✨ 核心特性

### 1. 自动生成
每次实验完成后自动生成两种格式的报告：
- **JSON格式**（机器可读）- 适合数据分析
- **Markdown格式**（人类可读）- 适合阅读查看

### 2. 完整数据
报告包含：
- ✅ 实验配置和参数
- ✅ 所有参与者信息
- ✅ 详细游戏结果
- ✅ 完整财务状况
- ✅ 所有交易历史
- ✅ 统计数据

### 3. 持久保存
- 报告保存在 `user://experiment_reports/`
- 使用时间戳命名，不会覆盖
- 可永久保存所有历史记录

## 🚀 如何使用

### 1. 运行实验
在游戏中打开GodUI控制台 → 点击"🎮 自定义实验"按钮 → 选择实验类型和参与者 → 开始实验

### 2. 查看完成日志
实验完成后，日志会显示：
```
📊 报告已生成并保存到: user://experiment_reports/
  • experiment_report_trust_20260105_143022.json
  • experiment_report_trust_20260105_143022.md
```

### 3. 访问报告
#### 在macOS上：
```
~/Library/Application Support/Godot/app_userdata/[项目名]/experiment_reports/
```

#### 在Windows上：
```
%APPDATA%\Godot\app_userdata\[项目名]\experiment_reports\
```

#### 在Linux上：
```
~/.local/share/godot/app_userdata/[项目名]/experiment_reports/
```

## 🔧 技术实现

### 修改的文件
- `script/ui/GameExperimentPanel.gd`

### 新增功能
1. **实验元数据记录**
   - 开始时间
   - 实验类型
   - 配置参数

2. **报告生成函数**
   - `_generate_report()` - 主函数
   - `_save_json_report()` - JSON格式保存
   - `_save_markdown_report()` - Markdown格式保存

3. **自动目录创建**
   - 自动创建 `experiment_reports/` 文件夹
   - 确保报告能正常保存

## 🎯 使用建议

### 数据分析
使用Python读取JSON报告：
```python

with open('experiment_report_trust_20260105_143022.json') as f:
    data = json.load(f)
    # 分析数据...
```

### 查看报告
用Markdown阅读器打开`.md`文件：
- VSCode
- Typora
- Obsidian

### 导出分享
将Markdown转换为PDF：
```bash
pandoc report.md -o report.pdf
```
