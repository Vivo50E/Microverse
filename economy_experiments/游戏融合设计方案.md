# 🎮 经济实验游戏融合设计方案

## 🎯 核心概念

将 Microverse 从"办公室模拟器"转变为"**经济行为实验室**"，玩家扮演**实验主持人**，观察和引导AI代理进行各种经济实验。

---

## 🌍 世界观重新设定

### 原设定 → 新设定

| 方面 | 原设定 | 新设定 |
|------|--------|--------|
| **场景** | 办公室 | 经济行为实验室 |
| **玩家角色** | 上帝视角/管理者 | 实验主持人/研究员 |
| **角色身份** | 员工 | 实验参与者/AI代理 |
| **角色目标** | 工作任务 | 参与经济实验，赚取金钱 |
| **交互方式** | 日常对话 | 实验任务、经济决策 |
| **进度体现** | 任务完成度 | 财富积累、实验数据 |

### 新的故事背景

```
欢迎来到"时空码头经济行为研究所"

你是一名实验经济学研究员，负责研究AI代理的经济行为。
在这个实验室中，8名AI代理自愿参与各种经济实验。
他们有自己的性格、偏好和决策风格。

你的任务：
- 设计和执行经济实验
- 观察代理的决策行为
- 收集和分析数据
- 发表研究成果
```

## 🎮 游戏玩法设计

### 核心循环

```
1. 准备阶段
   ↓
   玩家选择实验类型
   玩家选择参与代理
   玩家设置实验参数
   
2. 执行阶段
   ↓
   代理进行决策
   实时观察行为
   记录实验数据
   
3. 分析阶段
   ↓
   查看实验结果
   分析行为模式
   解锁新实验/奖励
   
4. 发展阶段
   ↓
   代理学习成长
   玩家获得声望
   解锁新功能
   
回到步骤1
```

### 玩家角色定位

**你是实验主持人**，可以：

1. **设计实验**
   - 选择实验类型（信任、最后通牒等）
   - 设置参数（初始禀赋、轮数）
   - 选择参与代理

2. **观察行为**
   - 实时查看代理决策
   - 监控财富变化
   - 记录特殊行为

3. **干预实验**（可选）
   - 给予奖励/惩罚
   - 改变实验条件
   - 植入特定记忆

4. **分析数据**
   - 查看统计结果
   - 比较不同代理
   - 发现行为模式

### 实验启动

```gdscript
# ExperimentLab.gd
extends Node2D

@onready var experiment_ui = $CanvasLayer/ExperimentUI
@onready var agent_manager = $AgentManager

func start_new_experiment(experiment_config: Dictionary):
	# 显示实验开始动画
	$AnimationPlayer.play("experiment_start")
	
	# 通知代理
	announce_to_agents("新的实验即将开始！")
	
	# 移动代理到实验桌
	var participants = experiment_config.participants
	for i in range(participants.size()):
		var agent = agent_manager.get_agent(participants[i])
		agent.move_to_experiment_desk(i)
	
	await get_tree().create_timer(2.0).timeout
	
	# 启动实验
	var experiment = ExperimentManager.new()
	add_child(experiment)
	experiment.load_experiment(experiment_config.path)
	experiment.setup_experiment()
	experiment.start_experiment()
	
	# 开始实时监控
	experiment_ui.start_monitoring(experiment)

func announce_to_agents(message: String):
	$NotificationBoard.show_message(message)
	for agent in agent_manager.get_all_agents():
		agent.show_bubble(message)
```
