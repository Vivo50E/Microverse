## 🆕 新增功能

### 1. 心理状态追踪系统 ⭐

现在可以追踪每个agent的8个心理维度：

| 维度 | 说明 | 范围 |
|------|------|------|
| 满意度 | 对当前状况的满意程度 | 0-100% |
| 压力 | 心理压力水平 | 放松 → 极度压力 |
| 自信心 | 对自己能力的信心 | 0-100% |
| 社会地位感 | 相对于他人的地位感知 | 0-100% |
| 心情 | 当前情绪状态 | 沮丧 → 非常愉快 |
| 动机 | 参与活动的动力 | 0-100% |
| 嫉妒 | 对他人的嫉妒程度 | 0-100% |
| 感激 | 感激程度 | 0-100% |

#### 示例输出
```
Alice:
- 心情: 低落 (0.4/1.0)
- 满意度: 45%
- 压力水平: 中等压力
- 嫉妒程度: 60% ⚠️

Monica:
- 心情: 愉快 (0.8/1.0)
- 满意度: 85%
- 压力水平: 放松
- 感激程度: 45% ✨
```

## 📊 数据分析示例

### 分析心理状态趋势

```python
import json
import matplotlib.pyplot as plt
from glob import glob

# 读取所有报告
reports = []
for file in sorted(glob("experiment_reports/*.json")):
    with open(file) as f:
        reports.append(json.load(f))

# 提取心理状态数据
agents_psych = {}
for report in reports:
    psych_states = report['results'].get('psychological_states', {})
    for name, state in psych_states.items():
        if name not in agents_psych:
            agents_psych[name] = {
                'satisfaction': [],
                'stress': [],
                'mood': [],
                'confidence': []
            }
        agents_psych[name]['satisfaction'].append(state['satisfaction'])
        agents_psych[name]['stress'].append(state['stress'])
        agents_psych[name]['mood'].append(state['mood'])
        agents_psych[name]['confidence'].append(state['confidence'])

# 绘制趋势图
fig, axes = plt.subplots(2, 2, figsize=(15, 10))

metrics = ['satisfaction', 'stress', 'mood', 'confidence']
titles = ['满意度趋势', '压力趋势', '心情趋势', '自信心趋势']

for idx, (metric, title) in enumerate(zip(metrics, titles)):
    ax = axes[idx // 2, idx % 2]
    for name, data in agents_psych.items():
        ax.plot(data[metric], label=name, marker='o')
    ax.set_title(title)
    ax.set_xlabel('实验次数')
    ax.set_ylabel('数值 (0-1)')
    ax.legend()
    ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('psychological_trends.png')
plt.show()
```

### 分析财富与心理状态的关系

```python
import numpy as np
from scipy.stats import pearsonr

# 提取财富和满意度数据
wealth_data = []
satisfaction_data = []

for report in reports:
    wallets = report['results']['wallets']
    psych_states = report['results']['psychological_states']
    
    for name in wallets.keys():
        if name in psych_states:
            wealth_data.append(wallets[name]['cash'])
            satisfaction_data.append(psych_states[name]['satisfaction'])

# 计算相关性
correlation, p_value = pearsonr(wealth_data, satisfaction_data)
print(f"财富与满意度的相关系数: {correlation:.3f} (p={p_value:.4f})")

# 绘制散点图
plt.figure(figsize=(10, 6))
plt.scatter(wealth_data, satisfaction_data, alpha=0.6)
plt.xlabel('财富 (¥)')
plt.ylabel('满意度 (0-1)')
plt.title(f'财富与满意度的关系 (r={correlation:.3f})')
plt.grid(True, alpha=0.3)
plt.savefig('wealth_satisfaction_correlation.png')
plt.show()
```

## 🔍 注意事项

### 1. 心理状态更新时机
- 心理状态在每次实验完成后更新
- 需要运行实验才能看到心理状态变化
- 初始状态为默认值（0.5）

### 2. 社会比较
- 心理状态会考虑与其他agent的比较
- 财富排名影响社会地位感和嫉妒程度
- 建议让所有8个agent都参与实验以获得完整数据

### 3. 数据持久化
- 心理状态保存在每次实验报告中
- 心理状态历史记录在agent对象中（不跨会话）
- 长期分析需要从报告文件中提取数据
