- ✅ 无需额外代码
- ✅ 开箱即用

#### 使用示例

```gdscript
# 方式1：编辑器中
# 1. 创建Button节点
# 2. 附加 ExperimentMenuButton.gd
# 3. 设置 panel_type 和 button_text

# 方式2：代码中
var btn = Button.new()
btn.text = "🧪 快速实验"
btn.set_script(load("res://script/ui/ExperimentMenuButton.gd"))
btn.panel_type = ExperimentMenuButton.PanelType.QUICK_PANEL
add_child(btn)
```
