# 🎮 游戏内实验系统 - 快速参考

## 🚀 三步开始

```
1. 按 ` 键 → 打开GodUI控制台
2. 点击 "🎮 自定义实验" 按钮
3. 选择实验类型 + 参与者 → 开始实验
```

## 📋 实验类型速查

| 实验 | 人数 | 参数 | 测试内容 |
|------|------|------|---------|
| 🤝 信任游戏 | 2人 | 禀赋、乘数 | 信任与互惠 |
| ⚖️ 最后通牒 | 2人 | 禀赋 | 公平偏好 |
| 🏛️ 公共物品 | 4+人 | 禀赋、乘数 | 合作与搭便车 |
| 👑 独裁者 | 2人 | 禀赋 | 纯粹利他 |

## 👥 角色性格速查

| 角色 | 特点 | 适合实验 |
|------|------|---------|
| **Alice** | 合作、信任高 | 信任游戏、公共物品 |
| **Jack** | 冒险、风险寻求 | 信任游戏（受托人） |
| **Grace** | 理性、公平 | 最后通牒、独裁者 |
| **Joe** | 理性最优化 | 所有实验 |
| **Lea** | 利他、慷慨 | 公共物品、独裁者 |
| **Monica** | 公平偏好 | 最后通牒 |
| **Stephen** | 风险厌恶 | 信任游戏（信任者） |
| **Tom** | 随机、不可预测 | 对照组 |


## 📊 结果解读

```
绿色数字 = 盈利 ✅
红色数字 = 亏损 ❌
白色数字 = 持平 ⚪
```

### 好结果
- 所有人都盈利 → 成功合作
- 财富差距小 → 公平分配
- 多回合盈利增加 → 学习效应

### 坏结果
- 有人严重亏损 → 被剥削
- 财富差距大 → 不平等
- 多回合盈利下降 → 信任崩溃

## 🔧 快捷操作

### 连续实验
```
1. 完成实验
2. 不关闭面板
3. 调整参数
4. 再次开始
→ 财富累积，观察学习
```

### 对比实验
```
实验A: Alice + Jack (乘数2)
实验B: Alice + Jack (乘数3)
→ 观察参数影响
```

### 轮换实验
```
第1轮: Alice + Jack
第2轮: Alice + Grace
第3轮: Alice + Tom
→ 观察Alice对不同对手的策略
```

## ⚠️ 注意事项

- ✅ 必须选择足够数量的参与者
- ✅ 财富会在同一会话中累积
- ✅ 重启游戏后财富重置
- ❌ 当前不支持保存实验历史
- ❌ 实验财富不影响游戏内容

## 🐛 问题排查

| 问题 | 解决方案 |
|------|---------|
| 按钮无反应 | 检查是否选够人数 |
| 没有角色列表 | 确保游戏场景已加载 |
| 结果不显示 | 等待实验完成 |
| Console报错 | 检查是否有语法错误 |
