# 🎮 如何在游戏中显示实验UI - 详细教程

## 问题：看不到实验UI？

别担心！按照这个教程，5分钟内就能在游戏中看到实验功能。

---

## 🎯 方法一：在 GodUI 中添加（推荐）

### 第一步：打开 GodUI 场景

1. 在 Godot 编辑器中，点击左上角 **场景 → 打开场景**
2. 导航到：`scene/ui/GodUI.tscn`
3. 双击打开

### 第二步：找到右侧面板

在场景树（Scene）中找到：

```
GodUI (Control)
└── HBoxContainer
    └── RightPanel (VBoxContainer)
        └── VBoxContainer
            ├── ImplantMemoryButton  ← 现有按钮
            ├── DiseaseButton
            ├── MoneyButton
            ├── EmotionButton
            ├── TaskButton
            ├── BackgroundButton
            └── ToggleUIButton
```

### 第三步：添加实验按钮

1. **右键点击** `VBoxContainer` 节点
2. 选择 **添加子节点**
3. 搜索并选择 `Button`
4. 按 **创建**
5. 将新按钮命名为 `ExperimentButton`

### 第四步：配置按钮

选中刚创建的 `ExperimentButton`，在右侧检查器（Inspector）中设置：

#### 基本属性
- **Text**: `🧪 快速实验`
- **Custom Minimum Size**: X=200, Y=40

#### 附加脚本
1. 在检查器最上方，点击 **脚本** 旁边的 📄 图标
2. 选择 **加载**
3. 导航到：`script/ui/ExperimentMenuButton.gd`
4. 点击 **打开**

#### 脚本参数（在检查器中会出现）
- **Panel Type**: 选择 `QUICK_PANEL` (值为 1)
- **Button Text**: `🧪 快速实验`

### 第五步：保存并运行

1. 按 `Ctrl+S`（Mac: `Cmd+S`）保存场景
2. 按 `F5` 运行游戏
3. 在游戏右侧面板中，你会看到新的 **🧪 快速实验** 按钮
4. 点击它！

## 🎯 方法二：通过代码添加（更快）

### 修改 GodUI.gd 脚本

1. 打开 `script/ui/GodUI.gd`
2. 找到 `_ready()` 函数（大约在第31行）
3. 在 `_ready()` 函数的**最后**添加以下代码：

```gdscript
func _ready():
	# ... 现有代码 ...
	
	# === 添加实验按钮 ===
	_add_experiment_button()

# 在文件末尾添加这个新函数
func _add_experiment_button():
	# 创建实验按钮
	var experiment_button = Button.new()
	experiment_button.name = "ExperimentButton"
	experiment_button.text = "🧪 快速实验"
	experiment_button.custom_minimum_size = Vector2(200, 40)
	
	# 附加脚本
	var script = load("res://script/ui/ExperimentMenuButton.gd")
	experiment_button.set_script(script)
	
	# 添加到右侧面板
	var right_vbox = $HBoxContainer/RightPanel/VBoxContainer
	right_vbox.add_child(experiment_button)
	
	# 移动到ToggleUIButton之前
	right_vbox.move_child(experiment_button, right_vbox.get_child_count() - 2)
	
	print("✅ 实验按钮已添加到 GodUI")
```

### 保存并运行

1. 按 `Ctrl+S` 保存文件
2. 按 `F5` 运行游戏
3. 看到按钮了吗？点击它！

## ❓ 常见问题

### Q1: 我按了F5，但是游戏没运行？

**A**: 确保你在 Godot 编辑器中，不是在游戏窗口中。按 `F5` 会运行主场景。

### Q2: 我看不到实验按钮？

**A**: 检查：
1. 是否保存了场景/脚本？（Ctrl+S）
2. 是否附加了正确的脚本？
3. 尝试关闭游戏重新运行（Shift+F5 停止，F5 重新运行）

### Q3: 点击按钮没反应？

**A**: 检查：
1. 按钮是否正确附加了 `ExperimentMenuButton.gd` 脚本？
2. 打开 Godot 控制台（底部），看有没有错误信息
3. 确认 Ollama 正在运行（`ollama list`）

### Q4: 面板显示不完整？

**A**: 尝试：
1. 调整游戏窗口大小
2. 检查快速面板的位置设置
3. 使用完整仪表板代替快速面板

### Q5: 实验无法启动？

**A**: 确认：
1. Ollama 正在运行：打开终端，运行 `ollama list`
2. API 设置正确：按 ESC → 设置 → API 设置
3. 实验配置文件存在：`economy_experiments/configs/experiments/`

## 📝 完整代码示例（方法二）

如果你想直接复制粘贴，这是完整的 `_add_experiment_button()` 函数：

```gdscript
# 在 GodUI.gd 文件末尾添加
func _add_experiment_button():
	"""添加实验室按钮到右侧面板"""
	
	# 检查是否已存在
	var right_vbox = $HBoxContainer/RightPanel/VBoxContainer
	if right_vbox.has_node("ExperimentButton"):
		print("⚠️ 实验按钮已存在")
		return
	
	# 创建按钮
	var experiment_button = Button.new()
	experiment_button.name = "ExperimentButton"
	experiment_button.text = "🧪 快速实验"
	experiment_button.custom_minimum_size = Vector2(200, 40)
	experiment_button.tooltip_text = "打开经济行为实验面板"
	
	# 附加脚本
	var script_path = "res://script/ui/ExperimentMenuButton.gd"
	if ResourceLoader.exists(script_path):
		var script = load(script_path)
		experiment_button.set_script(script)
		print("✅ 实验按钮脚本加载成功")
	else:
		push_error("❌ 找不到实验按钮脚本: " + script_path)
		return
	
	# 添加到面板
	right_vbox.add_child(experiment_button)
	
	# 移动到倒数第二个位置（ToggleUIButton之前）
	var toggle_button_index = -1
	for i in range(right_vbox.get_child_count()):
		if right_vbox.get_child(i).name == "ToggleUIButton":
			toggle_button_index = i
			break
	
	if toggle_button_index >= 0:
		right_vbox.move_child(experiment_button, toggle_button_index)
	
	print("✅ 实验按钮已添加到 GodUI 右侧面板")
```

然后在 `_ready()` 中调用：

```gdscript
func _ready():
	# ... 所有现有代码 ...
	
	# 在最后添加
	_add_experiment_button()
```
