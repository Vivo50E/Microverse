# ⏸️ 游戏暂停功能说明

## 问题

**Q: 实验进行时，主游戏场景还会继续运行吗？**

**A: 是的，默认情况下会继续运行！**

## 当前行为（默认）

当你运行实验时：

### ✅ 游戏继续运行
- 角色继续移动
- AI继续做决策
- 对话继续进行
- 时间继续流逝

### 为什么这样设计？
- 实验是"后台研究"
- 不打断游戏流程
- 可以同时观察游戏和实验
- 实验只使用角色的经济属性副本

---

## 🆕 可选暂停功能

现在你可以**选择**是否在实验期间暂停游戏！

### 界面位置

```
┌────────────────────────────────────┐
│  [实验类型] [参与者] [参数]         │
│                                    │
│  ☑️ 实验期间暂停游戏场景            │
│  ℹ️ 取消勾选可以同时观察游戏和实验  │
│                                    │
│  [▶ 开始实验]  [✖ 关闭]           │
└────────────────────────────────────┘
```

### 使用方法

#### 方式1：暂停游戏（专注实验）
```
1. ✅ 勾选"实验期间暂停游戏场景"
2. 开始实验
→ 游戏场景暂停
→ 角色停止移动
→ AI停止决策
→ 专注观察实验
```

#### 方式2：不暂停（同时观察）
```
1. ⬜ 不勾选（默认）
2. 开始实验
→ 游戏继续运行
→ 可以同时看游戏和实验
→ 更真实的"后台研究"感觉
```

## 🔧 技术细节

### 暂停时发生了什么？

#### 1. 暂停游戏场景
```gdscript
get_tree().paused = true
```
- 所有节点停止处理
- 物理停止
- 动画暂停

#### 2. 实验面板继续工作
```gdscript
process_mode = Node.PROCESS_MODE_ALWAYS
```
- 实验面板不受暂停影响
- 可以正常交互
- 日志正常更新

#### 3. 禁用AI决策
```gdscript
ai_agent.decision_timer.paused = true
```
- AI定时器暂停
- 不会做出新决策
- 不会发起对话

### 恢复时发生了什么？

实验完成或关闭面板时：
- ✅ 恢复`get_tree().paused`状态
- ✅ 恢复AI决策定时器
- ✅ 游戏继续从暂停点运行

## ⚠️ 注意事项

### 1. 暂停不保存游戏
暂停只是临时冻结，不会保存游戏状态。

### 2. 面板关闭自动恢复
如果在实验进行中关闭面板，游戏会自动恢复。

### 3. 实验独立运行
无论是否暂停游戏，实验都正常运行。

### 4. 不影响实验数据
暂停游戏不会影响实验结果和角色经济决策。

### 5. UI仍然可用
暂停游戏后，实验面板和GodUI仍然可以交互。

## 🐛 故障排除

### Q: 勾选了暂停，但游戏还在动？
A: 检查是否有其他系统设置了PROCESS_MODE_ALWAYS。通常这不应该发生。

### Q: 实验完成后游戏没有恢复？
A: 重新打开实验面板并关闭它，或者按F5重启游戏。

### Q: 暂停后AI行为异常？
A: 这是正常的。AI定时器被暂停，恢复后需要等待下一个决策周期。

### Q: 可以在实验中途切换暂停状态吗？
A: 当前版本不支持。需要在实验开始前决定。
