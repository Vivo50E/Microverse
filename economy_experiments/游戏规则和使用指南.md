## 💰 经济系统规则

### 双轨经济体系

游戏中存在**两个独立的经济系统**：

#### 1️⃣ **研究员经济系统（你）**

**初始状态**：
- 研究经费：¥10,000
- 研究员等级：Lv.1
- 天数：第1天

**经费来源**：
- ✅ 完成每日目标获得奖励
- ✅ 解锁成就获得奖励
- ✅ 发表研究报告获得资助

**经费用途**：
- 💸 支付实验禀赋（给代理的实验启动资金）
- 💸 解锁新实验类型
- 💸 升级实验室设施

**每日目标**：
```
✅ 完成3个实验 → 奖励 ¥500
✅ 收集100条数据 → 奖励 ¥200
✅ 发现特殊事件 → 奖励 ¥1000
```

#### 2️⃣ **代理经济系统（AI角色）**

**为什么代理初始经济是¥0？**

这是核心设计理念：

1. **实验经济学原则**
   - 代理的财富**完全来自实验参与**
   - 没有"天生的财富"，一切靠实验赚取
   - 确保所有财富变化都是实验结果

2. **公平起点**
   - 所有代理从¥0开始，完全公平
   - 财富差距完全由决策能力和运气决定
   - 便于研究财富积累和不平等的形成

3. **实验禀赋机制**
   - 每次实验开始时，代理会获得**实验禀赋**（endowment）
   - 禀赋是临时的实验启动资金
   - 实验结束后，盈利归代理所有

**代理财富系统**：
```gdscript
初始财富：¥0
实验禀赋：每次实验获得（如¥100）
盈利累积：实验后增加
亏损扣除：实验后减少
```

**Wallet类的默认值**：
虽然`Wallet.gd`中默认初始是¥100，但在实验系统中：
- 代理创建时：`ExperimentLabManager`设置为¥0
- 实验开始时：临时获得禀赋
- 实验结束时：保留盈利，禀赋不退还

### 自主经济行为

除了参与你安排的实验，Agent 也会在场景中**自主进行经济互动**！

- **决策机制**：Agent 会根据性格和状态，主动发起交易、投资或借贷。
- **互惠循环**：当 A 给 B 钱时，B 可能会根据“互惠倾向”回礼。
- **详见文档**：[自主经济交互机制说明](./自主经济交互机制说明.md)

每位代理都有独特的经济决策风格：

| 代理 | 类型 | 决策特点 | 经济行为 |
|------|------|----------|----------|

| **Grace** | 利他主义型 | 温暖善良，关心他人 | 高合作率，愿意分享 |
| **Joe** | 理性最优化型 | 精确计算，追求最优解 | 数学决策，期望值最大化 |

### 经济性格参数（0.0-1.0）

每个代理有以下隐藏属性：

```gdscript
risk_aversion: 0.5      # 风险厌恶程度（高=更保守）
time_preference: 0.5    # 时间偏好（高=重视未来）
altruism: 0.5           # 利他程度（高=更慷慨）
fairness_concern: 0.5   # 公平关注（高=重视公平）
trust_level: 0.5        # 信任水平（高=更信任他人）
reciprocity: 0.5        # 互惠倾向（高=更倾向回报）
```

这些参数会影响代理在各种实验中的决策。

   位置：economy_experiments/configs/experiments/

   ```json
   {
     "experiment_name": "我的实验",
     "duration_minutes": 10,
     "agents": [
       {
         "name": "Alice",
         "personality": "configs/agents/risk_averse.json",
         "initial_cash": 100
       }
     ],
     "games": [
       {
         "type": "trust",
         "rounds": 5,
         "params": {
           "initial_endowment": 100,
           "multiplier": 3
         }
       }
     ]
   }
   ```

3. **在代码中加载**
   ```gdscript
   var exp_manager = ExperimentManager.new()
   exp_manager.load_experiment("res://economy_experiments/configs/experiments/my_experiment.json")
   exp_manager.setup_experiment()
   exp_manager.start_experiment()
   ```

## 📊 实验类型说明

### 1. 信任游戏（Trust Game）

**规则**：
- 两名玩家：信任者A、受托人B
- A获得初始禀赋（如¥100）
- A决定发送多少给B
- 发送金额×乘数（如×3）到达B
- B决定返还多少给A

**研究内容**：
- 信任水平
- 互惠行为
- 期望与实际回报

**示例**：
```
A初始：¥100
A发送：¥75 给B
B收到：¥75 × 3 = ¥225
B返还：¥150 给A

结果：
A最终：¥25 + ¥150 = ¥175 (盈利+¥75)
B最终：¥225 - ¥150 = ¥75 (盈利+¥75)
```

### 2. 最后通牒博弈（Ultimatum Game）

**规则**：
- 两名玩家：提议者A、响应者B
- A获得一笔钱（如¥100）
- A提议如何分配（如A:¥70, B:¥30）
- B可以接受或拒绝
- B接受：按提议分配
- B拒绝：双方都得¥0

**研究内容**：
- 公平感
- 拒绝不公平的代价
- 社会规范

### 3. 公共品博弈（Public Goods Game）

**规则**：
- 多名玩家（如4人）
- 每人获得初始禀赋（如¥100）
- 每人决定贡献多少到公共池
- 公共池总额×乘数（如×1.5）
- 平均分配给所有人

**研究内容**：
- 合作意愿
- 搭便车行为
- 社会困境

**示例**：
```
4名玩家，每人¥100，乘数1.5

情况1（都合作）：
- 每人贡献¥100
- 公共池：¥400
- 返还：¥400 × 1.5 ÷ 4 = ¥150/人
- 盈利：+¥50/人

情况2（1人搭便车）：
- 3人贡献¥100，1人贡献¥0
- 公共池：¥300
- 返还：¥300 × 1.5 ÷ 4 = ¥112.5/人
- 合作者：¥12.5/人
- 搭便车者：¥0 + ¥112.5 = ¥112.5
```

### 4. 独裁者博弈（Dictator Game）

**规则**：
- 两名玩家：独裁者A、接收者B
- A获得一笔钱（如¥100）
- A单方面决定给B多少
- B没有选择权，必须接受

**研究内容**：
- 纯粹利他主义
- 无社会压力下的慷慨度

## ❓ 常见问题

**Q: 为什么代理初始财富是¥0？**
A: 这是实验设计的一部分。所有财富来自实验，确保公平起点和可追踪性。

**Q: 实验禀赋从哪来？**
A: 从你的研究经费中支付，这是实验成本。

**Q: 代理会记住之前的实验吗？**
A: 会的！代理有学习系统，会基于过去经验调整决策。

**Q: 如何让代理变富？**
A: 让他们参与更多实验，特别是合作型实验更容易双赢。

**Q: 可以破产吗？**
A: 代理的财富可以变成负数（欠债），但不会影响参与新实验。

**Q: 经费用完了怎么办？**
A: 完成每日目标获得奖励，或者解锁成就获得经费。
