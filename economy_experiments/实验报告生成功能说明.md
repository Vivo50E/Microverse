# 实验报告生成功能说明

## 📊 功能概述

游戏内实验系统现在会在每次实验完成后自动生成详细的本地报告，包含完整的实验数据、参与者表现、财务状况和交易历史。

---

## 📁 报告存储位置

所有报告保存在：
```
user://experiment_reports/
```

在不同操作系统上的实际路径：
- **Windows**: `%APPDATA%\Godot\app_userdata\[项目名]\experiment_reports\`
- **macOS**: `~/Library/Application Support/Godot/app_userdata/[项目名]/experiment_reports/`
- **Linux**: `~/.local/share/godot/app_userdata/[项目名]/experiment_reports/`

---

## 📝 报告格式

每次实验生成两种格式的报告：

### 1. JSON 格式（机器可读）
**文件名**: `experiment_report_[类型]_[日期时间].json`

**用途**:
- 数据分析和统计
- 机器学习数据集
- 与其他工具集成
- 程序化处理

**示例**:
```
experiment_report_trust_20260105_143022.json
```

### 2. Markdown 格式（人类可读）
**文件名**: `experiment_report_[类型]_[日期时间].md`

**用途**:
- 阅读和查看实验结果
- 生成报告文档
- 分享实验记录
- 存档和备份

**示例**:
```
experiment_report_trust_20260105_143022.md
```

---

## 📋 报告内容

每个报告包含以下完整信息：

### 1. 实验信息
```markdown
- 实验类型（信任游戏、最后通牒等）
- 实验名称
- 开始时间和结束时间
- 实验总时长
```

### 2. 参与者列表
```markdown
- Alice
- Monica
```

### 3. 实验配置
```markdown
- 回合数: 1
- 初始禀赋: ¥100.00
- 乘数: 2.0（如适用）
```

### 4. 实验统计
```markdown
- 游戏场次: 1
- 总回合数: 1
- 总决策数: 2
```

### 5. 参与者财务状况表

| 参与者 | 现金 | 净资产 | 交易数 |
|--------|------|---------|--------|
| Alice  | ¥81.74 | ¥81.74 | 3 |
| Monica | ¥182.58 | ¥182.58 | 3 |

### 6. 详细游戏结果
每个游戏的完整信息：
- 游戏ID和类型
- 游戏时长
- 玩家表现（总收益、平均收益、参与回合）

### 7. 完整交易历史
每个参与者的所有交易记录：

| 类型 | 金额 | 来源/原因 | 余额 |
|------|------|-----------|------|
| initialization | ¥0.00 | system | ¥0.00 |
| deposit | ¥100.00 | experiment_endowment | ¥100.00 |
| withdraw | ¥64.32 | trust_game_sent | ¥35.68 |
| deposit | ¥46.06 | trust_game_return | ¥81.74 |

## 🎯 使用场景

### 场景 1: 实验数据分析
```python
# 读取JSON报告进行分析
import json

with open('experiment_report_trust_20260105_143022.json') as f:
    data = json.load(f)
    
    # 分析参与者收益
    for name, wallet in data['results']['wallets'].items():
        print(f"{name}: {wallet['cash']}")
```

### 场景 2: 查看实验记录
直接打开 `.md` 文件用 Markdown 阅读器查看：
- VSCode
- Typora
- Obsidian
- 或任何文本编辑器

### 场景 3: 生成实验报告
将 `.md` 文件导出为：
- PDF（用于打印或分享）
- HTML（用于网页展示）
- Word（用于进一步编辑）

### 场景 4: 数据归档
定期备份 `experiment_reports/` 文件夹，保存所有实验历史。

## 🔍 如何查找报告

### 方法 1: 通过系统文件管理器
1. 运行实验
2. 查看实验完成日志，记下报告文件名
3. 导航到 `user://` 目录
4. 打开 `experiment_reports/` 文件夹

### 方法 2: 通过游戏日志
实验完成后，日志会显示：
```
📊 报告已生成并保存到: user://experiment_reports/
  • experiment_report_trust_20260105_143022.json
  • experiment_report_trust_20260105_143022.md
```

### 方法 3: 通过Godot编辑器
1. 在Godot编辑器中，点击"项目" → "打开项目数据文件夹"
2. 导航到 `experiment_reports/` 文件夹

## 📊 数据持久化

### 报告保存时机
- ✅ 实验正常完成时自动生成
- ✅ 包含所有参与者的完整数据
- ✅ 包含所有游戏的详细结果

### 报告独立性
- 每次实验生成独立的报告文件

- 可累积保存所有历史实验

### 数据完整性
报告包含：
- ✅ 实验开始和结束时间
- ✅ 所有参与者的初始和最终状态
- ✅ 每一笔交易的详细记录
- ✅ 每个决策的完整数据
- ✅ 实验配置和参数

## 🎓 最佳实践

### 1. 定期备份
建议定期将 `experiment_reports/` 文件夹备份到：
- 云存储（Google Drive, Dropbox等）

- 外部硬盘

为大量实验创建子文件夹：
```
experiment_reports/
├── 2026-01/
│   ├── trust/
│   ├── ultimatum/
│   └── public_goods/
```

使用Python、R或Excel分析JSON数据：
- 收益分布
- 行为模式
- 策略演化
- 统计推断

### 4. 报告分享
将Markdown报告转换为PDF分享：
```bash
# 使用pandoc
pandoc report.md -o report.pdf

# 使用Markdown编辑器导出
VSCode → Markdown Preview Enhanced → Export
```

## 🐛 故障排查

### 问题 1: 找不到报告文件
**解决方案**:
1. 确认实验已正常完成（查看日志）
2. 检查 `user://` 目录的实际路径
3. 查看控制台是否有错误信息

### 问题 2: 报告内容不完整
**原因**: 可能实验异常终止
**解决方案**: 确保实验完整运行直到显示"实验完成"

### 问题 3: 无法打开JSON文件
**解决方案**: 使用文本编辑器或JSON查看器：
- VSCode
- Notepad++
- 在线JSON查看器
