# 🔬 场景实验系统 V2.0 设计说明

## 📋 核心理念

**主游戏场景本身就是实验环境** - 无需单独启动实验，系统在后台持续追踪所有agent的状态。

---

## 🏗️ 系统架构

### 原有设计（V1.0）

❌ "实验室模式"是一个独立的实验执行环境  
❌ 需要手动选择参与者和启动实验  
❌ 实验数据与主游戏场景分离  

### 新设计（V2.0）

✅ 主游戏场景 = 场景实验环境  
✅ 持续追踪所有agent的状态  
✅ 场景实验面板 = 监控和数据查看界面  
✅ 随时生成报告，无需等待实验完成  

---

## 🔧 核心组件

### 1. SceneExperimentTracker（场景实验追踪器）

**位置**: `economy_experiments/scripts/managers/SceneExperimentTracker.gd`

**功能**:
- 🔄 自动加载单例，游戏启动时自动运行
- 👥 为主场景中的所有角色创建 `EconomicAgent`
- 📊 每5秒自动更新所有agent的心理状态
- 💾 每5分钟自动生成场景报告
- 📡 发出信号通知财富变化、心理状态变化等

**核心方法**:

```gdscript
# 初始化场景agent
_initialize_scene_agents()

# 更新所有agent状态
_update_all_agents()

# 记录交互
record_interaction(agent_names: Array, interaction_type: String, details: Dictionary)

# 获取统计摘要
get_statistics_summary() -> Dictionary

# 获取财富排行榜
get_wealth_leaderboard() -> Array

# 获取心理状态摘要
get_psychological_summary() -> Dictionary

# 生成场景报告
generate_scene_report() -> String
```

**信号**:
```gdscript
signal agent_state_updated(agent_name: String, state: Dictionary)
signal wealth_changed(agent_name: String, new_wealth: float)
signal psychological_state_changed(agent_name: String, psych_state: Dictionary)
signal report_generated(report_path: String)
```

## 🚀 使用流程

### 1. 启动游戏

- **SceneExperimentTracker** 自动加载
- 自动为场景中的所有角色创建 `EconomicAgent`
- 开始后台追踪

### 2. 查看实时数据

1. 按 `` ` `` 键打开GodUI
2. 点击 **"🔬 场景实验"** 按钮
3. 查看实时统计和财富排行榜

### 3. 生成报告

- **自动生成**: 每5分钟自动保存一次
- **手动生成**: 点击 **"📊 生成报告"** 按钮
- **查看报告**: 点击 **"📁 打开报告文件夹"** 按钮

### 4. 报告内容

#### 场景报告包含：
- 📅 场景天数和运行时长
- 📊 统计摘要（总财富、交互次数等）
- 🏆 财富排行榜（包含心理状态）
- 💭 详细心理状态分析
- 💰 每个agent的详细财务数据
- 📝 经验统计和交易历史

## 🎯 关键特性

### 1. 无缝集成

```gdscript
# 主游戏场景中的角色自动被追踪
# 无需任何额外配置
var characters = get_tree().get_nodes_in_group("controllable_characters")
```

### 2. 持续追踪

```gdscript
# 每5秒更新一次心理状态
update_timer.wait_time = 5.0

# 考虑与其他agent的社会比较
agent.update_psychological_state(all_agents)
```

### 3. 自动报告

```gdscript
# 每5分钟自动生成报告
autosave_timer.wait_time = 300.0

# 报告包含完整的场景数据
generate_scene_report()
```

### 4. 实时监控

```gdscript
# 财富变化时发出信号
signal wealth_changed(agent_name: String, new_wealth: float)

# UI自动更新
scene_tracker.wealth_changed.connect(_on_wealth_changed)
```

## ⚙️ 配置说明

### 设置为自动加载

在Godot编辑器中：

1. **项目** → **项目设置**
2. **自动加载**标签
3. 添加:
   - **名称**: `SceneExperimentTracker`
   - **路径**: `res://economy_experiments/scripts/managers/SceneExperimentTracker.gd`
   - **启用**

### 调整追踪频率

在 `SceneExperimentTracker.gd` 中修改：

```gdscript
# 心理状态更新频率
var update_interval: float = 5.0  # 5秒

# 自动报告生成频率
var autosave_interval: float = 300.0  # 5分钟

# 启用/禁用自动报告
var auto_report_enabled: bool = true
```

## 📈 性能考虑

### 优化策略

1. **定时更新而非实时**: 每5秒更新一次心理状态
2. **信号驱动**: 只在财富变化时更新UI
3. **按需生成报告**: 手动生成或定时自动生成

### 性能指标

| 操作 | 频率 | 性能影响 |
|------|------|----------|
| 心理状态更新 | 每5秒 | 低（批量处理） |
| 财富监控 | 事件驱动 | 极低（信号） |
| 自动报告 | 每5分钟 | 低（后台） |
| UI更新 | 每2秒 | 低（仅UI线程） |

## 🐛 故障排查

### 问题1: 追踪器未启动

**症状**: 打开场景实验面板时显示"追踪器未初始化"

**解决方案**:
1. 检查是否将 `SceneExperimentTracker` 设置为自动加载
2. 在控制台查找错误信息
3. 确保路径正确

### 问题2: Agent未被追踪

**症状**: 财富榜中缺少某些角色

**解决方案**:
1. 确保角色在 `controllable_characters` 组中
2. 在场景中添加角色后，重启游戏

### 问题3: 心理状态未更新

**症状**: 所有agent心情都是默认值

**解决方案**:
1. 检查追踪器是否正在运行
2. 确认定时器是否启动
3. agent需要有财富变化才会更新心理状态
