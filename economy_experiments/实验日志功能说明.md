# 📜 实验日志功能说明

## 概述

游戏实验面板现在包含**实时日志系统**，可以详细观察实验进行的每一步！

## 🎨 界面布局

```
┌────────────────────────────────────────────────────────┐
│  🧪 游戏实验控制台 (900x700)                             │
├────────────────────────────────────────────────────────┤
│  [实验类型] [参与者] [参数设置]                          │
│  [▶ 开始实验] [✖ 关闭]                                  │
│  状态: ...                                             │
├──────────────────────┬─────────────────────────────────┤
│  📜 实验日志          │  📊 实验结果                     │
│  ┌─────────────────┐│  ┌─────────────────────────┐   │
│  │ [HH:MM:SS] ...  ││  │ 总游戏数: 1              │   │
│  │ [HH:MM:SS] ...  ││  │ 总决策数: 4              │   │
│  │ [HH:MM:SS] ...  ││  │                          │   │
│  │ (实时滚动)       ││  │ 参与者财富变化:           │   │
│  │                 ││  │   Alice: ¥25.50         │   │
│  └─────────────────┘│  │   Jack: ¥-10.00         │   │
│  [清空日志]          │  └─────────────────────────┘   │
└──────────────────────┴─────────────────────────────────┘
```

```

[HH:MM:SS] 实验类型: 信任游戏
[HH:MM:SS] 参与者: Alice, Jack
[HH:MM:SS] 回合数: 1 | 禀赋: ¥100
[HH:MM:SS] 乘数: 3.0
[HH:MM:SS] 
[HH:MM:SS] ✅ 实验启动成功
[HH:MM:SS] 🎬 实验 '信任游戏' 已启动
[HH:MM:SS] 👤 代理 Alice 已加入实验
[HH:MM:SS] 👤 代理 Jack 已加入实验
[HH:MM:SS] 🎮 游戏 'trust' 开始
```

### 2. 回合执行日志

#### 信任游戏
```
[HH:MM:SS] 
[HH:MM:SS] ━━━ 第 1 回合 ━━━
[HH:MM:SS]   💸 Alice 发送了 ¥75.00
[HH:MM:SS]   🔄 Jack 返还了 ¥150.00
[HH:MM:SS] ✓ 第 1 回合完成
[HH:MM:SS]   📊 发送金额: ¥75.00 → 乘数后: ¥225.00 → 返还: ¥150.00
```

#### 最后通牒游戏
```
[HH:MM:SS] ━━━ 第 1 回合 ━━━
[HH:MM:SS]   📋 Alice 提议分配 ¥40.00
[HH:MM:SS]   ✅ 接受 Jack 了提议
[HH:MM:SS] ✓ 第 1 回合完成
[HH:MM:SS]   📊 提议: ¥40.00 (接受 ✅) → 提议者: ¥60.00 | 响应者: ¥40.00
```

或者被拒绝：
```
[HH:MM:SS]   📋 Stephen 提议分配 ¥20.00
[HH:MM:SS]   ❌ 拒绝 Tom 了提议
[HH:MM:SS] ✓ 第 1 回合完成
[HH:MM:SS]   📊 提议: ¥20.00 (拒绝 ❌) → 提议者: ¥0.00 | 响应者: ¥0.00
```

#### 公共物品游戏
```
[HH:MM:SS] ━━━ 第 1 回合 ━━━
[HH:MM:SS]   🏛️ Alice 贡献了 ¥80.00
[HH:MM:SS]   🏛️ Grace 贡献了 ¥75.00
[HH:MM:SS]   🏛️ Lea 贡献了 ¥90.00
[HH:MM:SS]   🏛️ Tom 贡献了 ¥0.00
[HH:MM:SS] ✓ 第 1 回合完成
[HH:MM:SS]   📊 总贡献: ¥245.00 | 平均: ¥61.25 | 乘数后: ¥490.00 | 合作率: 75.0%
[HH:MM:SS]   ⚠️ 搭便车者: Tom
```

#### 独裁者游戏
```
[HH:MM:SS] ━━━ 第 1 回合 ━━━
[HH:MM:SS]   🎁 Lea 给出了 ¥60.00
[HH:MM:SS] ✓ 第 1 回合完成
[HH:MM:SS]   📊 给出: ¥60.00 (60.0%) → 独裁者: ¥40.00 | 接收者: ¥60.00
```

### 3. 实验完成日志

```
[HH:MM:SS] 🏁 游戏 'trust' 完成
[HH:MM:SS] 
[HH:MM:SS] === 实验完成 ===
```

## 🎨 颜色编码

日志使用不同颜色区分不同类型的信息：

| 颜色 | 用途 | 示例 |
|------|------|------|
| 🔵 **青色** (cyan) | 重要事件标题 | `=== 实验开始 ===` |
| 🟢 **绿色** (green) | 成功/完成 | `✅ 实验启动成功` |
| 🟡 **黄色** (yellow) | 进行中/警告 | `━━━ 第 1 回合 ━━━` |
| ⚪ **白色** (white) | 一般信息 | `实验类型: 信任游戏` |
| 🔴 **红色** (red) | 错误/失败 | `❌ 实验启动失败` |
| ⚫ **灰色** (gray) | 次要信息 | `[HH:MM:SS]` 时间戳 |
| 🟠 **橙色** (orange) | 警告 | `⚠️ 搭便车者: Tom` |
| 🔷 **水蓝** (aqua) | 数据统计 | `📊 发送金额: ¥75.00` |

## 🔍 日志信息详解

### 决策事件图标

| 图标 | 含义 | 游戏类型 |
|------|------|---------|
| 💸 | 发送金额 | 信任游戏 |
| 🔄 | 返还金额 | 信任游戏 |
| 📋 | 提出分配 | 最后通牒游戏 |
| ✅ | 接受提议 | 最后通牒游戏 |
| ❌ | 拒绝提议 | 最后通牒游戏 |
| 🏛️ | 贡献到公共池 | 公共物品游戏 |
| 🎁 | 给出金额 | 独裁者游戏 |

### 统计信息解读

#### 信任游戏统计
```
📊 发送金额: ¥75.00 → 乘数后: ¥225.00 → 返还: ¥150.00
     ↓              ↓                ↓
   信任者发送    受托人收到         受托人返还
```

#### 最后通牒统计
```
📊 提议: ¥40.00 (接受 ✅) → 提议者: ¥60.00 | 响应者: ¥40.00
      ↓        ↓            ↓                ↓
   给响应者   响应结果    提议者实际得  响应者实际得
```

#### 公共物品统计
```
📊 总贡献: ¥245.00 | 平均: ¥61.25 | 乘数后: ¥490.00 | 合作率: 75.0%
     ↓             ↓              ↓                ↓
  所有人贡献和  人均贡献    乘数后总额      贡献/禀赋比例
```

#### 独裁者统计
```
📊 给出: ¥60.00 (60.0%) → 独裁者: ¥40.00 | 接收者: ¥60.00
     ↓        ↓           ↓               ↓
  给出金额  给出比例   独裁者留下      接收者得到
```

## 🎯 使用场景

### 场景1：观察决策过程
```
目的：了解角色如何做决策
操作：运行实验，实时观察日志
关注：每个角色的具体决策数值
```

### 场景2：分析合作行为
```
目的：研究谁更合作
实验：公共物品游戏（4人）
观察：贡献金额 + 搭便车者名单
```

### 场景3：追踪学习效应
```
目的：观察角色如何学习
实验：多回合信任游戏
观察：回合间的行为变化
```

### 场景4：验证假设
```
目的：测试预期是否准确
实验：运行前预测结果
观察：对比日志中的实际决策
```

## 🛠️ 日志功能

### 自动滚动
- ✅ 日志自动滚动到最新内容
- ✅ 无需手动拖动滚动条
- ✅ 始终看到最新事件

### 时间戳
- ✅ 每条日志都有精确时间
- ✅ 格式：`[HH:MM:SS]`
- ✅ 便于追踪事件顺序

### 清空日志
- ✅ 点击"清空日志"按钮
- ✅ 清空所有历史日志
- ✅ 开始新的日志记录

### 分屏显示
- ✅ 左侧：实时日志
- ✅ 右侧：最终结果
- ✅ 可调整分割比例

## 💡 使用技巧

### 技巧1：对比日志
```
运行同样实验2次
截图或复制两次的日志
对比：决策是否一致？是否有学习？
```

### 技巧2：实时观察
```
不要等结果，盯着日志看
看到决策瞬间就能理解发生了什么
比最终结果更有洞察力
```

### 技巧3：记录数据
```
用Excel记录每次实验的关键日志数据
建立数据库
分析长期趋势
```

### 技巧4：验证预测
```
运行前预测："Alice会发送80%"
运行后查日志："Alice发送了¥75.00 (75%)"
评估预测准确性
```

### 技巧5：故事讲述
```
用日志讲述实验"故事"
"Alice信任了Jack，发送了75..."
让数据变得生动
```

## 🐛 常见问题

### Q: 日志太多，看不过来？
A: 可以先看回合结束的统计信息（📊），再回头看详细决策。

### Q: 如何保存日志？
A: 当前版本需要手动复制。未来会添加导出功能。

### Q: 日志影响性能吗？
A: 不会。日志是异步更新的，不影响实验速度。

### Q: 可以关闭日志吗？
A: 当前版本不支持。但你可以缩小日志面板或点击"清空日志"。
