# ✅ 游戏收益(Payoff)问题已修复

## 🐛 问题描述

**错误信息**：
```
Wallet.gd:50 @ deposit(): Wallet: Cannot deposit non-positive amount
```

**原因**：
游戏在记录玩家收益时，可能产生零或负数（玩家亏损），但 `Wallet.deposit()` 函数只接受正数金额，导致程序报错。

---

## 🔍 问题分析

### 影响的游戏

所有行为游戏都可能产生零或负收益：

1. **TrustGame（信任游戏）**
   - 使用净收益：`trustor_payoff - initial_endowment`
   - 如果信任者发送了钱但没有得到回报 → 负收益 ❌

2. **PublicGoodsGame（公共品游戏）**
   - 使用净收益：`payoff - endowment`
   - 如果贡献多但分配少 → 负收益 ❌

3. **UltimatumGame（最后通牒游戏）**
   - 如果提议被拒绝 → 双方都得0 ❌

4. **DictatorGame（独裁者游戏）**
   - 接收者可能得到0（如果独裁者不给）❌

### 问题代码

**GameBase.gd** (修复前):
```gdscript
func record_payoff(player_id: String, payoff: float):
	# ...
	if player.agent and player.agent.wallet:
		player.agent.wallet.deposit(payoff, "game_payout: " + game_type)
		# ❌ 如果 payoff <= 0 就会报错
```

---

## ✅ 修复方案

### 修改 GameBase.gd 的 record_payoff() 函数

**修复后的代码**:
```gdscript
func record_payoff(player_id: String, payoff: float):
	var player = get_player(player_id)
	if player.is_empty():
		push_error("GameBase: Player not found: " + player_id)
		return
	
	player.payoffs.append(payoff)
	
	# Update agent's wallet if in real economy mode
	if player.agent and player.agent.wallet:
		# Handle positive, negative, and zero payoffs
		if payoff > 0:
			# 正收益：存入钱包
			player.agent.wallet.deposit(payoff, "game_payout: " + game_type)
		elif payoff < 0:
			# 负收益（亏损）：从钱包扣除
			player.agent.wallet.withdraw(abs(payoff), "game_loss: " + game_type)
		# 如果收益为0，不做任何操作
```

### 逻辑说明

1. **正收益 (payoff > 0)**
   - 调用 `deposit()` 增加钱包余额
   - 来源标记为 "game_payout"

2. **负收益 (payoff < 0)**
   - 调用 `withdraw()` 减少钱包余额
   - 原因标记为 "game_loss"
   - 使用 `abs(payoff)` 确保金额为正

3. **零收益 (payoff == 0)**
   - 不做任何操作
   - 避免不必要的交易记录

## 💡 设计考虑

### 为什么允许负收益？

在真实经济实验中：

1. **现实性**
   - 真实世界中可以有亏损
   - 实验应该模拟真实的经济决策后果

2. **学习效果**
   - AI代理需要学习风险和收益
   - 亏损经历帮助代理改进策略

3. **游戏完整性**
   - 不应该人为改变游戏规则
   - 净收益是游戏设计的一部分

### 为什么不改为总是记录非负数？

❌ **不好的做法**：
```gdscript
# 强制改为0
record_payoff(player_id, max(0, net_gain))
```

**问题**：
- 扭曲了游戏结果
- 隐藏了真实的代理表现
- 影响数据分析的准确性

✅ **正确的做法**：
```gdscript
# 如实记录，正确处理
record_payoff(player_id, net_gain)  # 可能是负数
```
