# 🚀 场景实验系统快速设置指南

## ⚡ 5分钟快速设置

按照以下步骤启用场景实验系统。

---

## 📝 步骤1: 设置自动加载

### 在Godot编辑器中：

1. **打开项目设置**
   - 点击菜单栏：`项目` → `项目设置...`

2. **进入自动加载标签**
   - 在左侧面板找到并点击 `自动加载`

3. **添加场景实验追踪器**
   - **路径**: 点击文件夹图标，选择  
     ```
     res://economy_experiments/scripts/managers/SceneExperimentTracker.gd
     ```
   - **节点名称**: `SceneExperimentTracker`
   - **启用**: ✅ 勾选

4. **点击"添加"按钮**

5. **关闭项目设置**

### 验证设置

在自动加载列表中应该看到：

```
SceneExperimentTracker   res://economy_experiments/scripts/managers/SceneExperimentTracker.gd   [✓]
```

---

1. **启动游戏**

   应该看到以下消息：

   ✅ SceneExperimentTracker: 场景实验追踪器已启动

## 🔧 可选配置

### 调整更新频率

编辑 `SceneExperimentTracker.gd`：

```gdscript
# 在文件顶部找到：
var update_interval: float = 5.0  # 心理状态更新间隔（秒）
var autosave_interval: float = 300.0  # 自动报告生成间隔（秒）
var auto_report_enabled: bool = true  # 是否启用自动报告
```

修改数值后保存，重启游戏生效。

### 禁用自动报告

```gdscript
var auto_report_enabled: bool = false  # 禁用自动报告
```

这样只有手动点击"生成报告"才会生成。

## 🐛 故障排查

### 问题1: 控制台没有"追踪器已启动"消息

**原因**: 自动加载未正确设置

**解决方案**:
1. 重新检查项目设置 → 自动加载
2. 确保路径正确
3. 确保勾选了"启用"
4. 重启Godot编辑器

### 问题2: 场景实验按钮不存在

**原因**: GodUI未更新

**解决方案**:
1. 检查 `script/ui/GodUI.gd` 是否包含最新代码
2. 重启游戏
3. 如果仍然没有，在 GodUI 的 `_ready()` 中确认调用了 `_add_lab_mode_button()`

### 问题3: 打开面板显示"追踪器未初始化"

**原因**: 追踪器未加载或延迟加载

**解决方案**:
1. 等待几秒后再尝试打开面板
2. 检查控制台是否有错误信息
3. 确认自动加载设置正确

### 问题4: 财富榜为空

**原因**: 角色未加入 controllable_characters 组

**解决方案**:
1. 在场景树中选择角色节点
2. 在"节点"标签中添加到 `controllable_characters` 组
3. 重启游戏

## 💡 使用技巧

### 技巧1: 快速查看特定Agent

在财富排行榜中：
- 心情图标反映当前心理状态
- 😊 = 愉快（满意度高）
- 😐 = 平静（满意度中等）
- 😟 = 低落（满意度低）

### 技巧2: 定期查看报告

建议：
- 每次游戏会话结束前生成一次报告
- 对比不同时期的报告，分析趋势

### 技巧3: 使用自定义实验快速测试

- 运行几次不同类型的实验
- 观察agent心理状态的变化
- 分析财富差距对心理的影响
