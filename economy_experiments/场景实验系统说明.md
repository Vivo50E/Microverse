# 🔬 场景实验系统说明

## 📋 概述

**场景实验**是Microverse的核心功能，用于模拟完整的市场机制和行为实验。系统允许8个AI agent在场景中自由交互、交易，并长期观察他们的财富和心理状态变化。

---

## 🎯 核心目标

### 1. 完整市场模拟
- 模拟真实的经济交互环境
- 支持多种经济行为实验
- 观察市场机制如何影响agent行为

### 2. 长期观察
- 追踪agent财富变化
- 监测心理状态演化
- 分析行为模式和策略

### 3. 数据收集与分析
- 自动生成详细报告
- 记录所有交互和决策
- 支持长期趋势分析

---

## 🚀 如何使用

### 启动场景实验

1. **打开游戏**
   - 运行Microverse游戏（F5）

2. **进入场景实验模式**
   - 按 `` ` `` 键打开GodUI控制台
   - 点击右侧的 **"🔬 场景实验"** 按钮

3. **场景实验界面**
   ```
   ┌─────────────────────────────────────┐
   │  📅 第 1 天 | 场景实验 Lv.1        │
   │  💰 市场总额: ¥0.00                │
   │  🤝 交互次数: 0 次                 │
   │  📊 数据点: 0 条                   │
   ├─────────────────────────────────────┤
   │  🥇 Alice    ¥0.00                 │
   │  🥈 Monica   ¥0.00                 │
   │  🥉 Bob      ¥0.00                 │
   │     ...                             │
   └─────────────────────────────────────┘
   ```

4. **运行实验**
   - 点击 **"快速实验"** 按钮
   - 选择实验类型（信任游戏、最后通牒等）
   - 选择参与者
   - 开始实验

5. **查看结果**
   - 实验完成后自动更新财富榜
   - 点击 **"查看报告"** 查看详细数据
   - 报告自动保存到本地

## 💡 核心功能

### 1. 财富追踪

#### 实时财富榜
```

🥉 Bob      ¥50.00

```

#### 财富变化监控
- 每次实验后自动更新
- 显示排名变化
- 追踪累积财富

### 2. 心理状态追踪 ✨ 新功能

系统现在追踪每个agent的心理状态，包括：

#### 心理指标

| 指标 | 说明 | 影响因素 |
|------|------|----------|
| **满意度** | 对当前状况的满意程度 | 财富水平、最近收益 |
| **压力** | 心理压力水平 | 损失、债务 |
| **自信心** | 对自己能力的信心 | 成功率、财富 |
| **社会地位感** | 相对于他人的地位感知 | 财富排名 |
| **心情** | 当前情绪状态 | 满意度、压力 |
| **动机** | 参与活动的动力 | 心情、自信 |
| **嫉妒** | 对他人的嫉妒程度 | 财富差距 |
| **感激** | 感激程度 | 正面互动 |

#### 心情标签
- **非常愉快** (0.8-1.0)
- **愉快** (0.6-0.8)
- **平静** (0.4-0.6)
- **低落** (0.2-0.4)
- **沮丧** (0.0-0.2)

#### 压力标签
- **极度压力** (0.8-1.0)
- **高压力** (0.6-0.8)
- **中等压力** (0.4-0.6)
- **轻微压力** (0.2-0.4)
- **放松** (0.0-0.2)

### 4. 自动报告生成

#### 报告内容
每次实验完成后自动生成包含以下内容的报告：

1. **实验信息**
   - 实验类型和名称
   - 开始/结束时间
   - 实验时长

2. **参与者信息**
   - 参与者列表
   - 实验配置参数

3. **财务状况**
   - 每个agent的现金、净资产
   - 交易数量和历史

4. **心理状态** ✨ 新增
   - 心情和满意度
   - 压力和自信
   - 社会地位感
   - 嫉妒和感激程度

5. **详细游戏结果**
   - 每场游戏的完整数据
   - 玩家表现和收益

6. **交易历史**
   - 所有交易的详细记录
   - 金额、来源、余额

#### 报告格式
- **JSON格式** - 机器可读，适合数据分析
- **Markdown格式** - 人类可读，易于查看

#### 报告位置
```
user://experiment_reports/
├── experiment_report_trust_20260105_143022.json
├── experiment_report_trust_20260105_143022.md
└── ...
```

### 3. 分析报告数据

#### 使用Python分析JSON数据
```python
import json
import matplotlib.pyplot as plt

# 读取多个报告
reports = []
for file in glob.glob("experiment_reports/*.json"):
    with open(file) as f:
        reports.append(json.load(f))

# 分析财富变化
wealth_data = {}
for report in reports:
    for name, wallet in report['results']['wallets'].items():
        if name not in wealth_data:
            wealth_data[name] = []
        wealth_data[name].append(wallet['cash'])

# 绘制财富趋势图
for name, wealth in wealth_data.items():
    plt.plot(wealth, label=name)
plt.legend()
plt.xlabel('实验次数')
plt.ylabel('财富 (¥)')
plt.title('Agent财富变化趋势')
plt.show()
```

#### 分析心理状态趋势
```python
# 提取心理状态数据
psychological_data = {}
for report in reports:
    psych_states = report['results'].get('psychological_states', {})
    for name, state in psych_states.items():
        if name not in psychological_data:
            psychological_data[name] = {
                'satisfaction': [],
                'stress': [],
                'mood': []
            }
        psychological_data[name]['satisfaction'].append(state['satisfaction'])
        psychological_data[name]['stress'].append(state['stress'])
        psychological_data[name]['mood'].append(state['mood'])

# 绘制心理状态趋势
fig, axes = plt.subplots(3, 1, figsize=(10, 12))

for name, data in psychological_data.items():
    axes[0].plot(data['satisfaction'], label=name)
    axes[1].plot(data['stress'], label=name)
    axes[2].plot(data['mood'], label=name)

axes[0].set_title('满意度趋势')
axes[1].set_title('压力水平趋势')
axes[2].set_title('心情趋势')

for ax in axes:
    ax.legend()
    ax.set_xlabel('实验次数')
    ax.set_ylabel('数值 (0-1)')

plt.tight_layout()
plt.show()
```

## 🐛 故障排查

### 问题1: 心理状态显示为默认值
**原因**: agent未参与足够的实验
**解决方案**: 运行更多实验，心理状态会逐渐更新

### 问题2: 报告中缺少心理状态数据
**原因**: 使用了旧版本的实验系统
**解决方案**: 确保使用最新版本的代码

### 问题3: 财富榜未更新
**原因**: 实验未正常完成
**解决方案**: 查看日志确认实验是否成功完成
