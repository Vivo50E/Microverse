# 游戏模式Agent金钱不变问题 - 已修复 ✅

## 问题描述

在游戏模式下，当运行经济实验时，agent的金钱显示始终没有变化，即使实验已经完成并且游戏中的wallet确实被更新了。

## 问题根源

问题出在**实验结果数据流**的断裂：

1. ✅ **GameBase.record_payoff()** - 正确更新了agent的wallet
2. ✅ **ExperimentManager._collect_results()** - 正确收集了所有agent的wallet数据
3. ❌ **数据传递断裂** - ExperimentQuickPanel收到结果，但没有传递给ExperimentLabManager
4. ❌ **ExperimentLabManager** - 从未收到实验结果，无法更新agent_wealth字典

### 数据流示意图

**修复前（断裂）：**
```
ExperimentManager (有wallet数据)
    ↓ experiment_finished signal
ExperimentQuickPanel (收到结果)
    ↓ 没有传递！❌
ExperimentLabManager (agent_wealth没有更新)
    ↓
LabDashboardUI (显示旧的财富数据)
```

**修复后（连通）：**
```
ExperimentManager (有wallet数据)
    ↓ experiment_finished signal
ExperimentQuickPanel (收到结果)
    ↓ lab_manager.on_experiment_completed(results) ✅
ExperimentLabManager (agent_wealth更新)
    ↓
LabDashboardUI (显示新的财富数据)
```

### 2. ExperimentLabManager.gd

**修改的方法：**

#### `_update_agent_wealth()` - 正确解析wallet数据
```gdscript
func _update_agent_wealth(results: Dictionary):
    var wallets = results.get("wallets", {})
    if wallets.is_empty():
        print("ExperimentLabManager: 警告 - 没有找到wallet数据")
        return
    
    for agent_id in wallets.keys():
        var wallet_data = wallets[agent_id]
        # wallet.to_dict()返回完整数据
        var cash = wallet_data.get("cash", 0.0)
        var savings = wallet_data.get("savings", 0.0)
        var debt = wallet_data.get("debt", 0.0)
        var net_worth = wallet_data.get("net_worth", cash + savings - debt)
        
        # 更新agent财富
        agent_wealth[agent_id] = cash
        
        print("ExperimentLabManager: 更新 %s 财富 -> ¥%.2f" % [agent_id, net_worth])
```

**关键改进：**
- 添加空值检查
- 正确解析`wallet.to_dict()`返回的数据结构（包含cash、savings、debt等字段）
- 添加调试日志，便于追踪

## 技术细节

### Wallet数据结构

ExperimentManager收集的wallet数据格式（来自`Wallet.to_dict()`）：

```json
{
  "Alice": {
    "owner_id": "Alice",
    "cash": 125.5,
    "savings": 0.0,
    "debt": 0.0,
    "net_worth": 125.5,
    "assets": [],
    "transaction_history": [...]
  },
  "Jack": {
    "owner_id": "Jack",
    "cash": 87.3,
    ...
  }
}
```

### 为什么agent初始财富是¥200？

`ExperimentLabManager._initialize_agents()`中设置：
```gdscript
for agent_name in agent_names:
    if not agent_wealth.has(agent_name):
        agent_wealth[agent_name] = 200.0
```

这是实验室模式的**初始展示值**，与实验系统中的禀赋机制分离。实验开始后，这个值会被实际的wallet余额替换。

## 深层原因分析

这个问题的根本原因是**架构设计上的信息孤岛**：

1. **ExperimentManager是临时的** - 每次实验都创建新实例，实验结束后就不再使用
2. **ExperimentLabManager是持久的** - 作为单例管理长期状态（天数、经费、agent财富）
3. **缺少桥梁** - 两个系统之间没有建立明确的数据传递机制

修复方案通过在ExperimentQuickPanel中添加"桥梁"代码，将临时的实验结果同步到持久的实验室管理器中。
