# 🎮 游戏内实验系统使用指南

## 概述

现在可以在正常游戏模式下直接运行经济实验了！无需切换到实验室模式，可以让游戏中的AI角色参与各种经济行为游戏。

## 🚀 快速开始

### 1. 启动游戏
```
按 F5 运行游戏
```

### 2. 打开控制台
```
按 ` 键（反引号，ESC下方）打开GodUI控制台
```

### 3. 打开游戏实验面板
```
点击右侧的 "🎮 自定义实验" 按钮
```

### 可用的实验类型

#### 1. 信任游戏 (Trust Game)
- **需要人数**: 2人
- **参数**: 回合数、初始禀赋、乘数
- **玩法**: 
  - 信任者A获得初始禀赋
  - A决定发送多少给受托人B
  - 发送金额×乘数到达B
  - B决定返还多少给A

#### 2. 最后通牒游戏 (Ultimatum Game)
- **需要人数**: 2人
- **参数**: 回合数、初始禀赋
- **玩法**:
  - 提议者A获得一笔钱
  - A提议如何分配
  - 响应者B可以接受或拒绝
  - B拒绝则双方都得0

#### 3. 公共物品游戏 (Public Goods Game)
- **需要人数**: 4人（或更多）
- **参数**: 回合数、初始禀赋、乘数
- **玩法**:
  - 每人获得初始禀赋
  - 每人决定贡献多少到公共池
  - 公共池总额×乘数后平均分配

#### 4. 独裁者游戏 (Dictator Game)
- **需要人数**: 2人
- **参数**: 回合数、初始禀赋
- **玩法**:
  - 独裁者A获得一笔钱
  - A单方面决定给接收者B多少
  - B没有选择权

## 🎯 使用步骤

### 步骤1：选择实验类型
从下拉菜单中选择要运行的实验：
- 信任游戏
- 最后通牒游戏
- 公共物品游戏
- 独裁者游戏

### 步骤2：选择参与者
在参与者列表中**多选**（按住Ctrl/Cmd点击）需要的角色：
- Alice（合作倾向）
- Jack（风险寻求）
- Grace（理性分析）
- Joe（理性最优化）
- Lea（利他主义）
- Monica（公平偏好）
- Stephen（风险厌恶）
- Tom（随机决策）

**注意**：必须选择足够数量的参与者（根据实验类型）

### 步骤3：调整参数
根据需要调整实验参数：

- **回合数** (1-10)
  - 单回合：快速测试
  - 多回合：观察学习和适应

- **初始禀赋** (10-1000)
  - 较小值：更谨慎的决策
  - 较大值：更大胆的决策

- **乘数** (1-5)
  - 仅用于信任游戏和公共物品游戏
  - 较高值：更高的合作收益

### 步骤4：开始实验
点击 "▶ 开始实验" 按钮

### 步骤5：查看结果
实验完成后，结果区域会显示：
- 总游戏数
- 总决策数
- 每个参与者的财富变化

## 📊 实验结果解读

### 结果显示格式

```
实验结果

总游戏数: 1
总决策数: 4

参与者财富变化:
  Alice: ¥25.50    (绿色 = 盈利)
  Jack: ¥-10.00    (红色 = 亏损)
  Grace: ¥15.00
  Joe: ¥-5.50

提示：可以再次运行实验继续累积财富
```

### 财富累积机制

- **初始状态**: 所有角色财富为¥0
- **实验禀赋**: 每次实验开始时获得
- **盈利累积**: 实验后的净收益会累积
- **持续运行**: 可以多次运行实验，财富会持续累积

## 🔬 实验示例

## 🎮 游戏模式 vs 实验室模式

### 游戏模式（本功能）

**优点**：
- ✅ 无需切换界面
- ✅ 使用游戏中的真实角色
- ✅ 可以在游戏进行中随时运行
- ✅ 简单直观的控制面板

**限制**：
- ⚠️ 参与者数量受限于当前场景的角色
- ⚠️ 无法批量运行多个实验
- ⚠️ 没有详细的数据分析功能

### 实验室模式

**优点**：
- ✅ 完整的实验管理功能
- ✅ 可以创建任意数量的虚拟代理
- ✅ 支持批量实验和自动化
- ✅ 详细的数据导出和分析

**使用场景**：
- 🔬 正式的研究实验
- 📊 大规模数据收集
- 📈 长期实验追踪

## ⚙️ 高级功能

### 连续实验

可以多次运行实验，观察角色的学习和适应：

1. 运行第一次实验
2. 查看结果
3. 不关闭面板，直接调整参数
4. 再次点击"开始实验"
5. 财富会累积，角色会根据经验调整策略

### 混合实验

尝试不同的角色组合：

```

观察：
- 哪个组合最合作？
- 谁最会赚钱？
```

固定参与者，改变参数：

## 🐛 常见问题

### Q: 为什么点击"开始实验"没反应？
A: 检查以下几点：
1. 是否选择了足够数量的参与者？
2. 是否有实验正在运行中？
3. 查看Console是否有错误信息

### Q: 角色的财富会影响游戏吗？
A: 目前不会。实验财富是独立系统，不影响游戏内的其他机制。

### Q: 可以保存实验结果吗？
A: 当前版本结果仅显示在面板中。如需详细分析，请使用实验室模式。

### Q: 角色的决策是真实的AI决策吗？
A: 是的！每个角色都有独立的EconomicAgent，基于其性格参数做出决策。

### Q: 可以自定义角色性格吗？
A: 当前版本使用预设性格。未来版本可能支持自定义。

## 📝 技术细节

### 角色到EconomicAgent的转换

游戏启动时，系统会为每个角色创建对应的`EconomicAgent`：

```gdscript
var agent = EconomicAgent.new(character_name, 0.0)
agent.altruism = 0.6  # 根据角色设置
agent.trust_level = 0.7
agent.risk_aversion = 0.5
```

### 实验执行流程

```
1. 用户选择参与者和参数
2. 创建游戏实例（如TrustGame）
3. 将EconomicAgent添加到游戏
4. 游戏执行决策逻辑
5. 更新agent的wallet
6. 显示结果
```

### 数据持久化

- **实验期间**: 财富存储在EconomicAgent的wallet中
- **跨实验**: 同一游戏会话中财富会累积
- **重启游戏**: 财富重置为¥0
