# 📜 游戏日志系统说明

## 📋 概述

游戏日志系统在游戏界面实时显示所有交易、交互、事件等信息，让玩家能够清楚地看到游戏中发生的所有活动。

---

## 🎯 核心功能

### 1. 实时日志显示
- ✅ 交易记录（财富变化、交易详情）
- ✅ 交互记录（agent之间的互动）
- ✅ 对话记录（谁和谁对话）
- ✅ 实验记录（实验类型和参与者）
- ✅ 事件记录（时间变化、特殊事件）
- ✅ 系统消息（系统状态）
- ✅ 错误提示（错误信息）

### 2. 日志管理
- ✅ 自动滚动到最新日志
- ✅ 限制最大日志行数（100行）
- ✅ 清空日志功能
- ✅ 折叠/展开功能
- ✅ 显示/隐藏功能

### 3. 颜色分类
- 💚 **浅绿色** - 交易
- 💙 **浅蓝色** - 交互
- 💛 **黄色** - 实验
- 🧡 **橙色** - 事件
- 🩶 **灰色** - 系统
- ❤️ **红色** - 错误

## 🎮 使用方法

### 自动显示

游戏启动后，日志面板会自动显示在**左下角**：

```
┌────────────────────────────────────┐
│ 📜 交互日志  🗑️ ▼ ✖              │
├────────────────────────────────────┤
│ 08:00 [系统] 游戏日志系统已启动   │
│ 08:01 [财富] Alice 的财富变为 ¥100│
│ 08:02 [交互] Alice ↔ Bob: 对话    │
│ 08:03 [交易] Alice: ¥50.00 (实验) │
│ ...                                │
└────────────────────────────────────┘
```

### 控制按钮

#### 🗑️ 清空日志
- 点击清空所有日志记录
- 保留欢迎消息

#### ▼ 折叠/展开
- 点击折叠日志内容，只显示标题栏
- 再次点击展开

#### ✖ 隐藏日志
- 点击隐藏整个日志面板
- 需要通过代码重新显示

## 💻 编程接口

### 获取日志UI

```gdscript
var log_ui = get_tree().root.get_node_or_null("GameLogUI")
```

### 添加自定义日志

```gdscript
# 基本日志
log_ui.add_log("类别", "消息内容", "日志类型")

# 日志类型：
# - "transaction" (交易)
# - "interaction" (交互)
# - "experiment" (实验)
# - "event" (事件)
# - "system" (系统)
# - "error" (错误)
```

### 专用日志方法

#### 记录交易
```gdscript
log_ui.log_transaction("Alice", "Bob", 50.0, "借款")
# 输出: 💰交易 Alice → Bob: ¥50.00 (借款)
```

#### 记录交互
```gdscript
log_ui.log_interaction("Alice", "Bob", "握手", "友好问候")
# 输出: 🤝交互 Alice ↔ Bob: 握手 - 友好问候
```

#### 记录对话
```gdscript
log_ui.log_dialog("Alice", "Bob", "天气")
# 输出: 💬对话 Alice 与 Bob 对话 (主题: 天气)
```

#### 记录实验
```gdscript
log_ui.log_experiment("信任游戏", ["Alice", "Bob"], "Alice获胜")
# 输出: 🔬实验 信任游戏 实验 - 参与者: Alice, Bob | Alice获胜
```

#### 记录事件
```gdscript
log_ui.log_event("新的一天", "第5天开始")
# 输出: 📌事件 新的一天: 第5天开始
```

#### 记录错误
```gdscript
log_ui.log_error("无法加载配置文件")
# 输出: ❌错误 无法加载配置文件
```

### 控制日志UI

```gdscript
# 显示/隐藏
log_ui.show_log()
log_ui.hide_log()
log_ui.toggle_log()

# 设置位置
log_ui.set_position_preset("bottom_left")   # 左下角（默认）
log_ui.set_position_preset("bottom_right")  # 右下角
log_ui.set_position_preset("top_left")      # 左上角
log_ui.set_position_preset("top_right")     # 右上角

# 获取统计
var stats = log_ui.get_statistics()
print("总日志数: ", stats.total_logs)
print("交易数: ", stats.transaction_count)
print("交互数: ", stats.interaction_count)
```

## 🐛 故障排查

### 问题1: 日志UI不显示

**原因**: InitializeGameLog未添加到自动加载

**解决方案**:
1. 检查 project.godot 中是否有：
   ```
   InitializeGameLog="*res://script/ui/InitializeGameLog.gd"
   ```
2. 重启Godot编辑器
3. 运行游戏

### 问题2: 日志不更新

**原因**: 日志UI未正确初始化

**解决方案**:
```gdscript
# 在控制台检查
var log_ui = get_tree().root.get_node_or_null("GameLogUI")
print("日志UI存在: ", log_ui != null)
```

### 问题3: 日志位置不对

**解决方案**:
```gdscript
# 手动设置位置
var log_ui = get_tree().root.get_node_or_null("GameLogUI")
if log_ui:
    log_ui.set_position_preset("bottom_left")
```

## 📚 完整示例

### 在游戏中使用日志

```gdscript
# 在你的游戏脚本中
extends Node2D

var log_ui: Node

func _ready():
    # 获取日志UI
    log_ui = get_tree().root.get_node_or_null("GameLogUI")
    
    if log_ui:
        # 记录游戏开始
        log_ui.log_event("游戏开始", "Office场景已加载")
        
        # 设置位置（可选）
        log_ui.set_position_preset("bottom_right")

func on_agent_trade(from_agent: String, to_agent: String, amount: float):
    """agent交易时调用"""
    if log_ui:
        log_ui.log_transaction(from_agent, to_agent, amount, "市场交易")

func on_agent_interact(agent1: String, agent2: String):
    """agent交互时调用"""
    if log_ui:
        log_ui.log_interaction(agent1, agent2, "见面", "友好交流")

func on_experiment_complete(exp_type: String, participants: Array):
    """实验完成时调用"""
    if log_ui:
        log_ui.log_experiment(exp_type, participants, "实验成功完成")
```
