# ⏰ 游戏时间系统 - 立即设置指南

## 🚨 重要：必须完成以下步骤才能显示时间

---

## 📝 第一步：添加自动加载（最重要！）

### 在Godot编辑器中操作：

1. **打开项目设置**
   - 点击顶部菜单：`项目` → `项目设置...`
   - 或按快捷键：`Alt + P`（Windows/Linux）或 `Cmd + ,`（macOS）

2. **找到自动加载标签**
   - 在左侧列表中找到并点击 **`自动加载`**（AutoLoad）
   - 它通常在列表的顶部附近

3. **添加GameTimeSystem**
   
   在"自动加载"界面：
   
   a. **路径** 栏：
      - 点击文件夹图标 📁
      - 导航到：`script` → `GameTimeSystem.gd`
      - 或直接输入：`res://script/GameTimeSystem.gd`
   
   b. **节点名称** 栏：
      - 输入：`GameTimeSystem`
      - ⚠️ 名称必须完全一致！
   
   c. **启用** 复选框：
      - 确保勾选 ✅
   
   d. **点击"添加"按钮**

4. **验证添加成功**
   
   在自动加载列表中应该看到：
   ```
   GameTimeSystem    res://script/GameTimeSystem.gd    [✓]
   ```

5. **添加InitializeTimeUI（可选但推荐）**
   
   重复步骤3，添加第二个自动加载：
   
   - 路径：`res://script/ui/InitializeTimeUI.gd`
   - 节点名称：`InitializeTimeUI`
   - 启用：✅

6. **保存并关闭**
   - 点击"关闭"按钮
   - 设置会自动保存

---

## 🐛 故障排查

### 问题1: 控制台显示"GameTimeSystem未找到"

**原因**：GameTimeSystem没有正确添加到自动加载

**解决方案**：
1. 再次检查项目设置 → 自动加载
2. 确认路径：`res://script/GameTimeSystem.gd`
3. 确认名称：`GameTimeSystem`（注意大小写）
4. 确认勾选了"启用"复选框
5. 重启Godot编辑器后再试

### 问题2: 时间UI不显示

**可能原因A**：GameTimeSystem未启动
```
解决方案：查看控制台是否有"游戏时间系统已启动"消息
```

**可能原因B**：UI被其他元素遮挡
```
解决方案：
1. 运行游戏
2. 按 F3 打开调试信息
3. 查看节点树中是否有 GameTimeUI 节点
```

**可能原因C**：UI创建失败
```
解决方案：查看控制台是否有错误消息
```

### 问题3: 控制台有错误消息

**错误："Cannot load script"**
```
原因：脚本文件路径不正确或文件不存在
解决方案：
1. 确认文件存在
2. 检查文件路径拼写
3. 在Godot中右键点击脚本 → "复制路径"
```

**错误："Parse error"**
```
原因：脚本语法错误
解决方案：
1. 打开脚本文件
2. 查看Godot底部的错误面板
3. 修复所有语法错误
```

## 🎯 手动添加时间UI（备用方案）

如果自动添加不起作用，可以手动添加：

### 方法1：在Office场景中添加

1. **打开Office场景**
   - 在文件系统中双击：`scene/maps/Office.tscn`

2. **添加节点**
   - 选择根节点（Office）
   - 右键 → "添加子节点"
   - 搜索并选择 `Control` 节点
   - 重命名为 `TimeUIContainer`

3. **附加脚本**
   - 选中 `TimeUIContainer` 节点
   - 在"脚本"属性中点击 📄 图标
   - 点击"加载"
   - 选择 `script/ui/InitializeTimeUI.gd`

4. **保存场景**
   - Ctrl + S 保存

5. **运行测试**
   - F5 运行游戏

### 方法2：通过代码添加

编辑 `scene/maps/Office.tscn` 对应的脚本，在 `_ready()` 中添加：

```gdscript
func _ready():
    # ... 现有代码 ...
    
    # 添加时间UI
    _add_time_ui()

func _add_time_ui():
    var time_system = get_node_or_null("/root/GameTimeSystem")
    if not time_system:
        print("❌ GameTimeSystem未找到")
        return
    
    var time_ui_script = load("res://script/ui/GameTimeUI.gd")
    var time_ui = time_ui_script.new()
    time_ui.name = "GameTimeUI"
    add_child(time_ui)
    
    await get_tree().process_frame
    time_ui.set_position_preset("top_right")
    
    print("✅ 时间UI已添加")
```
