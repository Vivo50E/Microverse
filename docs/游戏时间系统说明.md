# ⏰ 游戏时间系统说明

## 📋 概述

游戏时间系统为Microverse提供了完整的游戏内时间管理功能，包括时间流逝、时间控制、时间显示等。

---

## 🎯 核心功能

### 1. 时间追踪
- ✅ 天数、小时、分钟的精确追踪
- ✅ 时间段识别（早晨、上午、中午、下午、傍晚、夜晚）
- ✅ 星期计算（周一到周日循环）
- ✅ 时间事件触发（8点上班、12点午餐等）

### 2. 时间控制
- ✅ 暂停/继续时间流逝
- ✅ 调整时间流速（0.1x - 10x）
- ✅ 设置具体时间
- ✅ 快进到指定时间

### 3. UI显示
- ✅ 实时显示当前时间
- ✅ 显示时间段和星期
- ✅ 时间控制按钮（暂停、流速）
- ✅ 颜色指示（正常/暂停/加速）

## 🚀 快速设置

### 步骤1: 设置自动加载

在Godot编辑器中：

1. **打开项目设置**
   - `项目` → `项目设置` → `自动加载`

2. **添加游戏时间系统**
   - 路径: `res://script/GameTimeSystem.gd`
   - 节点名称: `GameTimeSystem`
   - 启用: ✅

3. **保存并关闭**

### 步骤2: 添加时间UI到场景

有两种方式：

#### 方式A: 通过脚本添加（推荐）

在主场景或游戏场景的脚本中：

```gdscript
extends Node2D

func _ready():
    # 创建时间UI
    var time_ui = preload("res://script/ui/GameTimeUI.gd").new()
    time_ui.name = "GameTimeUI"
    add_child(time_ui)
    
    # 可选：设置位置
    time_ui.call_deferred("set_position_preset", "top_right")
```

#### 方式B: 在场景编辑器中添加

1. 打开主游戏场景（如`Office.tscn`）
2. 添加一个新的 `Control` 节点
3. 重命名为 `GameTimeUI`
4. 在"脚本"属性中附加 `res://script/ui/GameTimeUI.gd`
5. 保存场景

### 步骤3: 运行游戏

启动游戏后，你应该看到：

```
┌──────────────────────┐
│   📅 第1天 08:00    │
│   早晨 (周一)       │
├──────────────────────┤
│  ⏸️  │  1.0x        │
└──────────────────────┘
```

## 🎮 使用方法

### 基本控制

#### 暂停/继续时间
点击 **⏸️** 按钮或使用代码：

```gdscript
var time_system = get_node("/root/GameTimeSystem")
time_system.toggle_pause()  # 切换暂停状态
time_system.pause_time()    # 暂停
time_system.resume_time()   # 继续
```

#### 调整时间流速
点击 **1.0x** 按钮选择流速，或使用代码：

```gdscript
var time_system = get_node("/root/GameTimeSystem")
time_system.set_time_speed(2.0)  # 设置为2倍速
```

可用流速：`0.5x`, `1.0x`, `2.0x`, `5.0x`, `10.0x`

### 高级功能

#### 设置具体时间

```gdscript
var time_system = get_node("/root/GameTimeSystem")
time_system.set_time(5, 14, 30)  # 设置为第5天 14:30
```

#### 快进到指定时间

```gdscript
var time_system = get_node("/root/GameTimeSystem")
time_system.fast_forward_to(18)  # 快进到今天18:00
```

#### 获取当前时间

```gdscript
var time_system = get_node("/root/GameTimeSystem")

# 获取时间字符串
var time_str = time_system.get_time_string()  # "第1天 08:00"

# 获取详细时间
var detailed_str = time_system.get_detailed_time_string()  # "第1天 (周一) 08:00"

# 获取时间段
var period = time_system.get_time_period()  # "早晨"

# 获取统计信息
var stats = time_system.get_statistics()
print("当前天数: ", stats.current_day)
print("当前小时: ", stats.current_hour)
print("游戏总时长: ", stats.total_game_hours, " 小时")
```

#### 监听时间事件

```gdscript
func _ready():
    var time_system = get_node("/root/GameTimeSystem")
    
    # 监听时间变化
    time_system.time_changed.connect(_on_time_changed)
    
    # 监听天数变化
    time_system.day_changed.connect(_on_day_changed)
    
    # 监听小时变化
    time_system.hour_changed.connect(_on_hour_changed)

func _on_time_changed(day: int, hour: int, minute: int):
    print("时间: 第%d天 %02d:%02d" % [day, hour, minute])

func _on_day_changed(new_day: int):
    print("新的一天开始！第%d天" % new_day)

func _on_hour_changed(new_hour: int):
    print("新的一小时: %02d:00" % new_hour)
```

## ⚙️ 配置

### 调整时间流速

在 `GameTimeSystem.gd` 中修改：

```gdscript
# 每现实秒对应的游戏分钟数
var minutes_per_real_second: float = 1.0

# 举例：
# 1.0 = 1现实秒 = 1游戏分钟（默认）
# 2.0 = 1现实秒 = 2游戏分钟（更快）
# 0.5 = 1现实秒 = 0.5游戏分钟（更慢）
```

### 设置开始时间

```gdscript
# 游戏开始时的时间
var start_day: int = 1        # 第1天
var start_hour: int = 8       # 早上8点
var start_minute: int = 0     # 0分
```

## 💾 保存/加载

时间系统支持保存和加载：

```gdscript
# 保存游戏时
func save_game():
    var time_system = get_node("/root/GameTimeSystem")
    var time_data = time_system.save_data()
    
    var save_data = {
        "time": time_data,
        # ... 其他游戏数据
    }
    
    # 保存到文件
    var file = FileAccess.open("user://savegame.json", FileAccess.WRITE)
    file.store_string(JSON.stringify(save_data))
    file.close()

# 加载游戏时
func load_game():
    var file = FileAccess.open("user://savegame.json", FileAccess.READ)
    var json = JSON.new()
    json.parse(file.get_as_text())
    file.close()
    
    var save_data = json.data
    var time_system = get_node("/root/GameTimeSystem")
    time_system.load_data(save_data.time)
```

## 🐛 故障排查

### 问题1: 时间UI不显示

**原因**: `GameTimeSystem` 未设置为自动加载

**解决方案**:
1. 检查项目设置 → 自动加载
2. 确保 `GameTimeSystem` 已添加
3. 重启游戏

### 问题2: 时间不流逝

**原因**: 时间可能被暂停

**解决方案**:
```gdscript
var time_system = get_node("/root/GameTimeSystem")
print("是否暂停: ", time_system.is_paused)
if time_system.is_paused:
    time_system.resume_time()
```

### 问题3: 时间流逝太快/太慢

**解决方案**:
```gdscript
var time_system = get_node("/root/GameTimeSystem")

# 调整每秒对应的游戏分钟数
time_system.set_minutes_per_second(1.0)  # 默认值

# 或调整时间流速倍数
time_system.set_time_speed(1.0)  # 正常速度
```
